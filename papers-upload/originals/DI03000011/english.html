Q1(b) State and Prove De-Morgan’s theorems4 marks

Question as printed: Q1(b) State and Prove De-Morgan’s theorems

First theorem: the complement of a sum equals the product of the complements:

(A + B)′ = A′B′

Second theorem: the complement of a product equals the sum of the complements:

(AB)′ = A′ + B′

Proof by truth table:

AB(A+B)′A′B′(AB)′A′+B′
001111
010011
100011
110000

The columns on the two sides of each identity are identical for every input combination; therefore both theorems are proved. The laws extend to any number of variables, e.g. (ABC)′ = A′ + B′ + C′.

Q1(c) Explain different types of binary code.7 marks

Question as printed: Q1(c) Explain different types of binary code.

A binary code is a pattern of bits used to represent a number, letter or other symbol. Common types include:

Code typeDescription and example
Weighted numeric code — 8421 BCDEach decimal digit is encoded separately in four bits using weights 8, 4, 2, 1. Example: 5910 = 0101 1001 in BCD. BCD 1010–1111 are invalid digit codes.
Other weighted code — 2421A four-bit weighted decimal code with bit weights 2, 4, 2, 1; some decimal digits have more than one possible bit pattern unless a specific code table is fixed.
Non-weighted — Excess-3Add 3 to each decimal digit and encode the result in four-bit binary. Example: decimal digit 5 → 5+3=8 → 1000. It is self-complementing.
Non-weighted — Gray codeAdjacent code words differ in only one bit; useful in position encoders and K-map ordering.
Alphanumeric — ASCIIThe original ASCII is a 7-bit code for letters, digits, punctuation and control characters; for example, A = 6510 = 10000012.

Pure binary and BCD are different: 5810 is 1110102 in pure binary but 0101 1000 in BCD.

Q1(c) OR Write steps for subtraction in 2’s complement methods.explain each method with appropriate example7 marks

Question as printed: Q1(c) OR Write steps for subtraction in 2’s complement methods.explain each method with appropriate example

Steps to calculate A − B using 2’s complement:

  1. Write A and B with the same number of bits.
  2. Find the 2’s complement of B: invert every bit, then add 1.
  3. Add A to the 2’s complement of B.
  4. If an end carry is produced, discard it; the remaining bits are a positive result.
  5. If there is no end carry, the sum is a negative result in 2’s-complement form. Take its 2’s complement to find the magnitude and attach a minus sign.

Positive result: 22 − 13 using 5 bits:

Q2(c) Explain Universal Gate in details.7 marks

Question as printed: Q2(c) Explain Universal Gate in details.

A universal gate can be used by itself to construct NOT, AND and OR gates; consequently, any Boolean function can be implemented using only that gate type. NAND and NOR are universal gates.

Using NAND only:

Required functionNAND implementation
NOTA′ = A NAND A
ANDAB = (A NAND B) NAND (A NAND B)
ORA+B = (A NAND A) NAND (B NAND B)

Using NOR only:

Required functionNOR implementation
NOTA′ = A NOR A
ORA+B = (A NOR B) NOR (A NOR B)
ANDAB = (A NOR A) NOR (B NOR B)

They are called universal because all basic gates—and therefore any combinational logic circuit—can be built from repeated NANDs or repeated NORs. This can simplify manufacturing and reduce the number of IC types used.

Q2(a) OR Describe positive and negative logic.3 marks

Question as printed: Q2(a) OR Describe positive and negative logic.

Positive logic: the higher voltage level represents logic 1 (HIGH) and the lower level represents logic 0 (LOW).

Negative logic: the higher voltage level represents logic 0 and the lower voltage level represents logic 1. The electrical circuit and voltage waveforms are unchanged; only the logical interpretation is reversed. For a 5 V / 0 V system, positive logic interprets 5 V as 1 and 0 V as 0, while negative logic interprets 5 V as 0 and 0 V as 1. De Morgan’s laws explain why NAND/NOR gate descriptions change with logic polarity.

Q3 · Canonical forms and Karnaugh maps

Q3(a) Explain the canonical sum of product.3 marks

Question as printed: Q3(a) Explain the canonical sum of product.

Canonical Sum of Products (canonical SOP) is the OR (sum) of all minterms for which the Boolean function is 1. Each product (AND) term contains every input variable exactly once, either complemented or uncomplemented. It is written as F = Σm(indices).

Example: for F(A,B)=1 on rows 01 and 10,

F = Σm(1,2) = A′B + AB′

Canonical SOP can be read directly from the truth-table rows where the output is 1.

Q3(b) Explain the min term and max term.4 marks

Question as printed: Q3(b) Explain the min term and max term.

A minterm is an AND/product term containing every variable once. It is 1 for exactly one input combination. For index bits 101 (A=1, B=0, C=1), the minterm is m5 = AB′C.

A maxterm is an OR/sum term containing every variable once. It is 0 for exactly one input combination. For the same 101 row, the maxterm is M5 = A′ + B + C′, which evaluates to 0 only for A=1,B=0,C=1.

Thus a function may be written as a sum of its 1-minterms, Σm(...), or a product of its 0-maxterms, ΠM(...).

In a Karnaugh map, a group is formed from adjacent 1-cells (and optionally don’t-care X-cells) whose count is a power of two:

TermCells in groupVariables eliminated
Pair2 adjacent cells1 variable
Quad4 adjacent cells2 variables
Octet8 adjacent cells3 variables

Groups must be rectangular in the K-map’s Gray-code layout. Edge cells wrap around and count as adjacent; diagonal cells are not adjacent. A variable that changes within a group is eliminated. Use the largest groups possible and cover every required 1.

Q3(b) OR Explain Karnaugh Map with suitable example.4 marks

Question as printed: Q3(b) OR Explain Karnaugh Map with suitable example.

A Karnaugh map (K-map) is a graphical method for minimizing Boolean functions. Its cells represent minterms in Gray-code order so that adjacent cells differ in only one variable. Put 1s in the function’s minterm cells, form the largest possible power-of-two groups, then write one product term per group by retaining only variables that remain constant.

Example: F(A,B,C)=Σm(1,3,5,7). The 1s occupy all cells where C=1; one group of four eliminates A and B, leaving F=C.

Example 3-variable K-map (rows A=0,1; columns BC=00, 01, 11, 10)

10110

Groups may wrap across edges and may overlap if that reduces the expression.

Q4(a) Explain combinational circuit with block diagram.3 marks

Question as printed: Q4(a) Explain combinational circuit with block diagram.

A combinational circuit is a digital logic circuit whose output at any time depends only on its present input values. It has no memory or stored state; there is no feedback from a stored output to determine a later state.

General form: n present inputs → combinational logic → m outputs.

Q5 · Sequential circuits and flip-flops

Q5(a) Explain sequential circuit with block diagram.3 marks

Question as printed: Q5(a) Explain sequential circuit with block diagram.

A sequential circuit is a logic circuit whose output depends on the present inputs and the stored previous state. It combines combinational logic with memory elements (latches or flip-flops), usually controlled by a clock. Feedback carries the present state into the logic that determines the next state.

Block relation: present inputs + present state → combinational logic → outputs and next state; the memory stores the next state for the next clock event.

Q5(b) Explain Associative law of Boolean algebra.4 marks

Question as printed: Q5(b) Explain Associative law of Boolean algebra.

The associative law states that regrouping variables does not change the result.

OR: (A + B) + C = A + (B + C)
AND: (AB)C = A(BC)

For example, with A=1, B=0, C=1, both OR groupings evaluate to 1, and both AND groupings evaluate to 0. The law allows multi-input logic expressions to be grouped conveniently without changing their function.

Q5(c) What is Flip Flops? Explain JK flip-flop in detail7 marks

Question as printed: Q5(c) What is Flip Flops? Explain JK flip-flop in detail

A flip-flop is a bistable sequential circuit that stores one bit, Q. A JK flip-flop is a clock-controlled improvement of the SR flip-flop; J acts like Set, K like Reset, and feedback removes the invalid SR input combination. On the active clock edge its operation is:

JKQ(n+1)Operation
00Q(n)No change / hold
010Reset
101Set
11Q′(n)Toggle

Its characteristic equation is:

Q(n+1) = JQ′(n) + K′Q(n)

When J=K=1 it toggles. A level-triggered JK device can suffer race-around if the clock pulse remains active long enough for repeated feedback toggles; edge-triggered or master–slave JK flip-flops avoid this problem.

Q5(c) OR Explain applications of flip flop in detail.7 marks

Question as printed: Q5(c) OR Explain applications of flip flop in detail.

A flip-flop stores one bit and is a building block for sequential systems. Important applications are:

  • Memory and registers: one flip-flop stores one bit; a group stores a word or temporarily holds data.
  • Shift registers: transfer or convert data between serial and parallel forms.
  • Counters: cascaded T/JK flip-flops count clock pulses in digital clocks, timers and event counters.
  • Frequency division: a toggling flip-flop divides its clock frequency by two; cascaded stages divide by powers of two.
  • Control and state machines: store the current state of a controller or sequence detector.
  • Switch debouncing / event storage: an SR latch can hold a clean switch state or record that an event occurred.
  • Data synchronisation: D flip-flops sample and transfer signals between clocked stages.

Q1 · Network fundamentals and topologies

Q.1 (a) Define computer network and list out its applications.3 marks

Question as printed: Q.1 (a) Define computer network and list out its applications.

A computer network is a collection of autonomous computing devices connected by communication links and protocols so they can exchange data and share resources.

Applications: sharing files, printers and storage; web and email; messaging and video conferencing; remote access and cloud services; online banking, shopping and education; distributed processing; industrial monitoring and control; and entertainment/media streaming.

Q.1 (b) Explain Line Configuration with suitable diagram.4 marks

Question as printed: Q.1 (b) Explain Line Configuration with suitable diagram.

Line configuration describes how communication devices are attached to a transmission link.

  • Point-to-point: a dedicated link connects exactly two devices. The link’s capacity is not shared with other stations; examples include a direct leased line or a device-to-switch connection.
  • Multipoint (multidrop): more than two devices share one link. Capacity may be shared spatially or by taking turns in time; access rules are needed to avoid collisions. It can reduce cabling cost, but devices share bandwidth and a fault on the common segment may affect several stations.
Q.1 (c) Define Physical Topology. Explain any two topologies in detail.7 marks

Question as printed: Q.1 (c) Define Physical Topology. Explain any two topologies in detail.

Physical topology is the physical arrangement of network devices (nodes) and the links/cables that connect them.

Star topology: every device has a separate link to a central hub or, more commonly, switch. It is easy to add a node and isolate a faulty cable; a failed end link usually affects only that node. It requires more cable than a bus and depends on the central device—its failure can stop the star.

Ring topology: each node is connected to two neighbours to form a closed loop; data or a token passes around the ring. It can provide orderly access with few collisions. A single link/node failure can interrupt a simple ring, and adding or removing a node may disrupt service unless a protected/dual-ring design is used.

Q.1 (c) OR List the types of networks. Explain in detail.7 marks

Question as printed: Q.1 (c) OR List the types of networks. Explain in detail.

Networks are commonly classified by their geographic scope and purpose:

  • PAN (Personal Area Network): a few metres around one person; for example, a phone connected to a smartwatch over Bluetooth.
  • LAN (Local Area Network): a home, office, lab or building; typically privately managed and high speed. Ethernet and Wi-Fi are common LAN technologies.
  • CAN (Campus Area Network): connects LANs across a campus, university or industrial site.
  • MAN (Metropolitan Area Network): interconnects sites across a town or city; a metro fibre network is an example.
  • WAN (Wide Area Network): spans large geographic areas and links distant LANs/MANs using carrier infrastructure. The Internet is the largest global internetwork.

These size boundaries are approximate; a network may also be described by ownership, access or technology (for example, a private enterprise network or wireless LAN).

Q2 · Network layers and protocols

Q.2 (a) Write down full form of: MAC, FTP, LLC.3 marks

Question as printed: Q.2 (a) Write down full form of: MAC, FTP, LLC.

  • MAC: Media Access Control (the data-link sublayer that controls access to a shared medium; the term is also used for a link-layer address).
  • FTP: File Transfer Protocol, an application-layer protocol for transferring files over a TCP/IP network.
  • LLC: Logical Link Control, the IEEE 802 data-link sublayer above MAC that provides logical link services and identifies upper-layer protocols.
Q.2 (b) Write a short note on Data Link Layer.4 marks

Question as printed: Q.2 (b) Write a short note on Data Link Layer.

The Data Link Layer (OSI Layer 2) provides node-to-node delivery across a single link. It accepts packets from the network layer and encapsulates them in frames.

Typical functions include framing and frame delimiting, link-layer (MAC) addressing, controlling access to a shared medium, and detecting transmission errors (for example, with a frame check sequence). Some link protocols also provide flow/error recovery. In IEEE 802 LANs the layer is commonly divided into LLC (logical link control) and MAC (medium access control). A switch forwards frames using MAC addresses; frame delivery across a routed path is performed separately on each link.

Q.2 (c) Explain TCP/IP model with functions of each layer.7 marks

Question as printed: Q.2 (c) Explain TCP/IP model with functions of each layer.

The TCP/IP model describes the protocol suite used on the Internet. A common four-layer presentation is:

LayerMain functionsExample protocols / data unit
ApplicationServices for user/network applications; application message formats and exchanges.HTTP(S), DNS, FTP, SMTP; message/data
TransportProcess-to-process delivery, port multiplexing; TCP reliability/ordering/flow control or UDP datagrams.TCP segment / UDP datagram
InternetLogical IP addressing and routing packets between networks; best-effort delivery.IPv4/IPv6, ICMP; IP packet/datagram

At the sender, each layer adds its control information (encapsulation); at the receiver, the matching layers interpret and remove it. TCP/IP’s application layer combines functions that OSI separates into application, presentation and session layers. Textbooks sometimes split link and physical functions into separate layers, giving a five-layer teaching model.

Q.2 (a) OR Differentiate between connection-oriented and connection-less services.3 marks

Question as printed: Q.2 (a) OR Differentiate between connection-oriented and connection-less services.

Connection-oriented service establishes logical communication state before data transfer and may maintain sequence, acknowledgement, retransmission and flow control. It is suitable when reliable, ordered delivery is required; TCP is an example.

Connectionless service sends independent packets/datagrams without setting up a transport connection. Each packet carries addressing information; delivery, order and duplicate protection are not guaranteed by the service. It has less setup overhead and suits simple request/response or real-time traffic; UDP is an example. IP is also connectionless at the network layer.

Q.2 (b) OR Write a short note on Physical Layer.4 marks

Question as printed: Q.2 (b) OR Write a short note on Physical Layer.

The Physical Layer (OSI Layer 1) transmits raw bits over a physical medium. It defines the electrical, optical or radio representation of bits, signal encoding/modulation, bit rate, bit timing/synchronization, connectors and pin assignments, cable/radio characteristics and physical topology. It specifies how a bit stream is placed on and recovered from the medium; it does not interpret frames or network addresses. Copper cable, fibre-optic links and radio channels are examples of physical media.

Q3 · Transmission media and networking devices

Q.3 (a) Explain Twisted Pair Cable in detail.3 marks

Question as printed: Q.3 (a) Explain Twisted Pair Cable in detail.

Twisted-pair cable contains two separately insulated copper conductors twisted together. The twist helps reduce electromagnetic interference and crosstalk; multiple pairs are often bundled in a jacket. It is inexpensive, flexible and easy to terminate, and is widely used for telephone wiring and Ethernet LANs (for example, through an RJ-45-style connector). Performance depends on category, length, installation and interference.

UTP (Unshielded Twisted Pair) has no additional metallic shield: it is low-cost and easy to install but more susceptible to external interference. STP (Shielded Twisted Pair) adds foil/braid shielding around pairs or the cable: it can reduce interference, but costs more and needs correct grounding and installation.

Q.3 (a) OR Write a short note on Hub.3 marks

Question as printed: Q.3 (a) OR Write a short note on Hub.

A hub is a basic multiport repeater used to connect devices in an Ethernet LAN. It operates at the physical layer: an incoming signal is regenerated and repeated to all other ports, without learning MAC addresses or selecting a destination. All connected devices share bandwidth and one collision domain in classic half-duplex Ethernet. Hubs are simple but inefficient and insecure compared with switches, so modern LANs normally use switches instead.

Q.3 (c) OR List out Unguided Media. Explain any One in detail.7 marks

Question as printed: Q.3 (c) OR List out Unguided Media. Explain any One in detail.

Unguided (wireless) media transmit electromagnetic signals through air or space rather than along a cable. Main types include radio waves, terrestrial microwaves, infrared and satellite links.

Microwave transmission: uses relatively high-frequency radio signals and directional antennas. Terrestrial microwave links are commonly point-to-point and usually require line of sight; repeaters can extend the path. Satellite communication is a microwave link relayed through a satellite. Advantages include high capacity, broad coverage and installation without a continuous cable route. Limitations include blockage by terrain/buildings, alignment requirements, interference and weather-related fading (especially at higher frequencies). It is used for backhaul, point-to-point links and satellite communications.

Q4 · IP addressing and subnetting

Q.4 (a) Define IPv6 protocol and list out its features.3 marks

Question as printed: Q.4 (a) Define IPv6 protocol and list out its features.

IPv6 (Internet Protocol version 6) is the Internet-layer protocol designed to identify interfaces and route packets across IP networks, succeeding IPv4.

  • 128-bit source and destination addresses, written in colon-separated hexadecimal.
  • Very large address space and hierarchical prefix allocation.
  • Fixed 40-byte base header with a simpler forwarding header; optional information uses extension headers.
  • No broadcast; supports unicast, multicast and anycast.
  • Routers do not fragment packets; fragmentation, if needed, is handled by the source using an extension header and path-MTU discovery.
  • Supports stateless address autoconfiguration and neighbour discovery through ICMPv6; designed to work with IPsec protocols.

Q.4 (c) Define Subnetting. Explain Subnet Masking with example.7 marks

Question as printed: Q.4 (c) Define Subnetting. Explain Subnet Masking with example.

Subnetting divides an IP network prefix into smaller logical networks by borrowing bits from the host portion. A subnet mask (or prefix length) has 1-bits for the network/subnet portion and 0-bits for the host portion. The network address is found by bitwise AND of the IP address and mask.

Example: IP address 10.6.24.20 with mask 255.255.240.0. The mask is /20 (20 leading 1-bits). In the third octet, 24 AND 240 = 16, so the network address is 10.6.16.0/20. This subnet spans 10.6.16.0 through 10.6.31.255; for ordinary host assignment, usable addresses are 10.6.16.1–10.6.31.254, with 10.6.31.255 as broadcast.

Subnet-mask calculation

Address: 10.6.24.20     00001010.00000110.00011000.00010100
Mask:    255.255.240.0   11111111.11111111.11110000.00000000
AND:     10.6.16.0       00001010.00000110.00010000.00000000

Q.4 (a) OR Define IPv4 protocol and list out its features.3 marks

Question as printed: Q.4 (a) OR Define IPv4 protocol and list out its features.

IPv4 (Internet Protocol version 4) is a connectionless, best-effort Internet-layer protocol that carries datagrams between source and destination addresses across interconnected networks.

  • Uses 32-bit addresses, conventionally written as four decimal octets.
  • Provides logical addressing and routing across networks.
  • Uses a variable-length header (minimum 20 bytes) with fields such as TTL, protocol, checksum and fragmentation controls.
  • Does not guarantee delivery, ordering, error recovery or duplicate suppression; reliability is provided by higher-layer protocols when needed.
  • Supports unicast, multicast and broadcast addressing.
  • Uses subnet masks/prefixes and may be configured manually or through DHCP; ARP is commonly used for local IPv4 address resolution.

Q.4 (c) OR Draw and Explain IPv4 Header in details.7 marks

Question as printed: Q.4 (c) OR Draw and Explain IPv4 Header in details.

An IPv4 header is at least 20 bytes and may grow to 60 bytes when options are present. The Internet Header Length (IHL) is measured in 32-bit words.

  • Version (4 bits): value 4 for IPv4; IHL (4): header length.
  • DSCP/ECN (8): service/forwarding treatment and congestion notification.
  • Total Length (16): bytes in the entire IPv4 datagram (header plus data).
  • Identification (16), Flags (3), Fragment Offset (13): support fragmentation and reassembly.
  • TTL (8): decremented by each router; packet is discarded when it expires.
  • Protocol (8): identifies the next payload protocol, such as TCP or UDP.
  • Header Checksum (16): detects errors in the header and is recomputed as TTL changes.
  • Source and Destination Address (32 bits each): IPv4 endpoints.
  • Options and padding (variable): optional control information and alignment to a 32-bit boundary.

The header is encapsulated with payload; routers examine destination and relevant control fields to forward the datagram.

Q5 · Network security

Q.5 (a) List and discuss various security terms.3 marks

Question as printed: Q.5 (a) List and discuss various security terms.

  • Asset: data, device, service or other resource that has value and needs protection.
  • Threat: a potential cause of harm or security compromise.
  • Vulnerability: a weakness that a threat can exploit.
  • Attack: an attempt or action that exploits a vulnerability.
  • Risk: the likelihood and potential impact of a threat exploiting a vulnerability.
  • Security control/safeguard: a technical, administrative or physical measure that reduces risk.
  • Authentication / authorization: verifying an identity / deciding what that identity may do.
  • Confidentiality, integrity and availability: the core security objectives commonly called the CIA triad.
Q.5 (b) Explain threats to security: Intruders and Insiders.4 marks

Question as printed: Q.5 (b) Explain threats to security: Intruders and Insiders.

Intruders are unauthorized users who attempt to access a system, misuse privileges or evade controls. They may be external attackers or someone using a compromised account. Common categories are a masquerader (outsider impersonating an authorized user), a misfeasor (authorized user abusing privileges) and a clandestine user who gains supervisory control and hides activity.

Insiders are people with legitimate access—employees, contractors or administrators—who intentionally misuse it, act carelessly, or whose accounts/devices are compromised. They may steal or expose data, sabotage services or bypass procedures. Defences include least privilege, separation of duties, strong authentication, timely access reviews, logging and monitoring, backups, staff awareness and incident-response procedures.

Q.5 (c) Define Firewall and explain its design principles in detail.7 marks

Question as printed: Q.5 (c) Define Firewall and explain its design principles in detail.

A firewall is a hardware/software security control that monitors and filters traffic between networks or security zones according to a defined policy.

Core design principles for a secure firewall are:

  1. All traffic between the protected network and other networks should pass through the firewall. Prevent alternate, uncontrolled paths.
  2. Only traffic authorized by the security policy should be allowed. Use explicit rules and least privilege; default-deny is safer than unrestricted access.
  3. The firewall itself must be secure. Harden and patch it, restrict administrative access, minimize enabled services, and protect its configuration.

Additional good practice includes stateful inspection, network segmentation/DMZ for public services, logging and alerting, rule review, change control, redundancy, and defence in depth. A firewall reduces exposure but cannot stop every attack—for example, malicious content arriving through an allowed service still needs endpoint and application controls.

Q.5 (a) OR Define Security basics (CIA) in detail.3 marks

Question as printed: Q.5 (a) OR Define Security basics (CIA) in detail.

The CIA triad summarizes three fundamental information-security objectives:

  • Confidentiality: information is disclosed only to authorized people/systems. Controls include access control, encryption and data minimization.
  • Integrity: information and systems remain accurate and complete, and unauthorized changes are prevented or detected. Controls include hashes/MACs, digital signatures, permissions, validation and audit logs.
  • Availability: authorized users can access services and data when needed. Controls include redundancy, backups, patching, capacity planning, recovery and denial-of-service protection.

Security policy balances these objectives: a control that strengthens one may affect another, so risks and operational needs must be considered.

Q.5 (b) OR Explain Different Malwares in brief.4 marks

Question as printed: Q.5 (b) OR Explain Different Malwares in brief.

Malware is software or code intended to harm a system, disrupt operation, steal information or gain unauthorized control. Common forms include:

  • Virus: attaches to a host file/program and spreads when that host is run.
  • Worm: self-propagates between systems, often over networks, without needing to attach to a host program.
  • Trojan horse: appears useful or legitimate but performs hidden malicious actions; it does not self-replicate by definition.
  • Ransomware: encrypts or blocks access to data and demands payment.
  • Spyware/keylogger: secretly monitors activity or captures information.
  • Rootkit: hides malicious presence and helps maintain privileged access.
  • Adware/bot malware: displays unwanted advertising or turns a device into a remotely controlled bot.

Use trusted updates, endpoint protection, least privilege, cautious handling of attachments and links, and offline/versioned backups to reduce risk.

Q.5 (c) OR List out and explain different types of firewalls in brief.7 marks

Question as printed: Q.5 (c) OR List out and explain different types of firewalls in brief.

Common firewall types include:

  • Packet-filtering (stateless) firewall: permits/blocks packets using fields such as source/destination IP, protocol and port. It is efficient but has limited application awareness and does not track connection state.
  • Stateful-inspection firewall: tracks connection state and permits packets that belong to valid sessions as well as policy-approved new connections.
  • Circuit-level gateway: validates transport/session establishment (for example, TCP handshakes) and relays connections without deeply inspecting application content.
  • Application-level gateway / proxy firewall: terminates and proxies application sessions, enabling protocol-aware inspection and filtering; it can add latency and requires suitable proxy support.
  • Next-generation firewall (NGFW): combines stateful filtering with deeper application/user awareness and often intrusion-prevention or threat-intelligence features.
  • Host-based firewall: runs on an individual endpoint; network-based firewall protects traffic between network zones. These deployment types can be combined.

Firewalls are also described by the layer inspected: packet filters mainly use network/transport headers; proxies can inspect application-layer traffic. No single type replaces endpoint security, secure configuration and monitoring.

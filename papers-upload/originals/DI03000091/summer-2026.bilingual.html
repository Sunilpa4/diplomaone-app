Q1 · Fundamentals of measurementપ્ર.1 · માપનના પાયા

Q.1 (a) Define: True value, Correction, Repeatability. (3 marks)પ્ર.1 (અ) વ્યાખ્યા આપો: સાચી કિંમત, કરેક્શન, રિપીટેબિલિટી. (૦૩ ગુણ)3 marks૦૩ ગુણ

True value: The actual value of the measurand under defined conditions (ideal, error-free). In practice approximated by a higher-accuracy reference.

Correction: Value added algebraically to the measured (indicated) value to obtain a more accurate result: Correction = True value − Indicated value = − Error. Charts/tables give corrections for an instrument.

Repeatability: Closeness of agreement among repeated measurements of the same measurand under the same conditions (same operator, instrument, location, short time) with same method. Expressed as spread/standard deviation; poor repeatability indicates random errors/noise.

True value (સાચી કિંમત): નિર્ધારિત conditions હેઠળ measurand ની વાસ્તવિક કિંમત (ideal, ભૂલ વગરની). વ્યવહારમાં વધુ accurate reference થી અંદાજવામાં આવે.

Correction (સુધારો): વધુ સાચું પરિણામ મેળવવા માપેલી (દર્શાવેલ) કિંમતમાં બીજગણિતીય રીતે ઉમેરાતી કિંમત: Correction = True value − Indicated value = − Error. Charts/tables instrument માટે corrections આપે.

Repeatability (રિપીટેબિલિટી): એક જ measurand ના એક જ conditions (એ જ operator, instrument, સ્થળ, ટૂંકો સમય) હેઠળ અને એક જ method થી repeated માપન વચ્ચે નિકટતાનો મેળ. Spread/standard deviation તરીકે દર્શાવાય; નબળી repeatability random errors/noise બતાવે.

Q.1 (b) Draw and explain Block diagram of instrumentation system. (4 marks)પ્ર.1 (બ) ઇન્સ્ટ્રુમેન્ટેશન સિસ્ટમનો બ્લોક ડાયાગ્રામ દોરીને સમજાવો. (૦૪ ગુણ)4 marks૦૪ ગુણ

Generalised instrumentation system:

  1. Primary sensing element / transducer — contacts measurand (temperature, pressure, displacement etc.) and converts to usable form (e.g., thermocouple → mV, LVDT → AC voltage).
  2. Signal conditioning — amplification, filtering, linearisation, cold-junction compensation, modulation/demodulation, A/D conversion to make signal suitable.
  3. Signal processing / transmission — computation, compensation, telemetry (4-20 mA, fieldbus).
  4. Display / recording / control — indicator, recorder, PLC/DCS; feedback to actuator if closed-loop.

Example: Temperature → RTD → bridge + amplifier → ADC → microcontroller display → relay for heater.

સામાન્ય ઇન્સ્ટ્રુમેન્ટેશન સિસ્ટમ:

  1. Primary sensing element / transducer (સેન્સિંગ એલિમેન્ટ) — measurand (temperature, pressure, displacement વગેરે) નો સંપર્ક કરે અને ઉપયોગી સ્વરૂપમાં ફેરવે (દા.ત. thermocouple → mV, LVDT → AC voltage).
  2. Signal conditioning (સિગ્નલ કન્ડીશનીંગ) — amplification, filtering, linearisation, cold-junction compensation, modulation/demodulation, A/D conversion — સિગ્નલને યોગ્ય બનાવે.
  3. Signal processing / transmission — computation, compensation, telemetry (4-20 mA, fieldbus).
  4. Display / recording / control — indicator, recorder, PLC/DCS; closed-loop હોય તો actuator ને feedback.

ઉદાહરણ: Temperature → RTD → bridge + amplifier → ADC → microcontroller display → heater માટે relay.

Q.1 (c) OR Explain different types of torque in instrument. (7 marks)પ્ર.1 (ક) OR ઇન્સ્ટ્રુમેન્ટના વિવિધ ટોર્ક વિશે સમજાવો. (૦૭ ગુણ)7 marks૦૭ ગુણ

Three essential torques in an indicating instrument:

  1. Deflecting torque (Td): Produced by the measurand (magnetic, thermal, electrostatic, electrodynamic effect) — proportional to current/voltage/quantity. Causes pointer to deflect. Example: Td = B·N·A·I for PMMC, Td ∝ I² for MI/electrodynamometer.
  2. Controlling torque (Tc): Opposes Td, increases with deflection θ; provides equilibrium (Td = Tc at steady reading). Two types:
    • Spring control: Phosphor-bronze spiral springs (also lead current) — Tc ∝ θ (linear scale).
    • Gravity control: Small weight on arm — Tc ∝ sinθ (non-linear, needs vertical instrument, no springs).
  3. Damping torque (Tdamp): Opposes motion (∝ angular velocity) — suppresses oscillations, gives quick settling.
    • Air friction: Piston or vane in chamber (MI instruments).
    • Eddy-current: Aluminium former/disc moving in permanent magnetic field → induced currents oppose motion (PMMC, induction meters).
    • Fluid friction: Vane in oil/silicone — used where vibrations high.

At steady state Td = Tc; damping only during movement. Proper damping = critical/under-critical for fast reading without overshoot.

Indicating instrument માં ત્રણ essential torques:

  1. Deflecting torque (Td): Measurand દ્વારા ઉત્પન્ન (magnetic, thermal, electrostatic, electrodynamic effect) — current/voltage/quantity ના પ્રમાણમાં. Pointer ને deflect કરાવે. ઉદા.: PMMC માટે Td = B·N·A·I, MI/electrodynamometer માટે Td ∝ I².
  2. Controlling torque (Tc): Td નો વિરોધ કરે, deflection θ સાથે વધે; સંતુલન આપે (steady reading પર Td = Tc). બે પ્રકાર:
    • Spring control: Phosphor-bronze spiral springs (current પણ લઈ જાય) — Tc ∝ θ (linear scale).
    • Gravity control: હાથ પર નાનું વજન — Tc ∝ sinθ (non-linear, instrument vertical રાખવું પડે, springs નહીં).
  3. Damping torque (Tdamp): ગતિનો વિરોધ (angular velocity ના પ્રમાણમાં) — oscillations દબાવે, ઝડપી settling આપે.
    • Air friction: Chamber માં piston અથવા vane (MI instruments).
    • Eddy-current: Permanent magnetic field માં aluminium former/disc ફરે → induced currents ગતિનો વિરોધ (PMMC, induction meters).
    • Fluid friction: Oil/silicone માં vane — vibrations વધુ હોય ત્યાં.

Steady state પર Td = Tc; damping ફક્ત હલનચલન દરમિયાન. યોગ્ય damping = overshoot વગર ઝડપી reading માટે critical/under-critical.

Q2 · Potentiometers, bridges and Meggerપ્ર.2 · પોટેન્શિયોમીટર, બ્રિજ અને મેગર

Q.2 (a) Draw a diagram of potentiometers and explain its working. (3 marks)પ્ર.2 (અ) પોટેન્શિયોમીટરની આકૃતિ દોરો અને તેનું કાર્ય સમજાવો. (૦૩ ગુણ)3 marks૦૩ ગુણ

Principle (Poggendorff / null comparison): Unknown EMF balanced against known voltage drop along a uniform slide wire — at balance no current from unknown source, hence no loading error.

Simple slide-wire potentiometer: Battery drives working current through rheostat + slide wire AB. Unknown EMF connected via galvanometer + jockey to sliding contact J. Move J until galvanometer shows zero.

At balance: Ex = Iwork × RAJ (or lAJlAB × VAB)

Calibrate working current with standard cell (1.0186 V) first; then measure unknown accurately.

સિદ્ધાંત (Poggendorff / null comparison): Unknown EMF ને uniform slide wire પર known voltage drop સામે balance કરાય — balance પર unknown source માંથી કોઈ current નહીં, તેથી loading error નહીં.

સાદો slide-wire potentiometer: Battery rheostat + slide wire AB માં working current ચલાવે. Unknown EMF galvanometer + jockey દ્વારા sliding contact J સાથે જોડેલ. Galvanometer zero બતાવે ત્યાં સુધી J ખસેડો.

Balance પર: Ex = Iwork × RAJ (અથવા lAJlAB × VAB)

પહેલાં standard cell (1.0186 V) થી working current calibrate કરો; પછી unknown ચોકસાઈથી માપો.

Q.2 (b) Explain Crompton potentiometer with neat diagram. (4 marks)પ્ર.2 (બ) ક્રોમ્પ્ટન પોટેન્શિયોમીટરનું ઓપરેશન આકૃતિ સાથે સમજાવો. (૦૪ ગુણ)4 marks૦૪ ગુણ

Crompton (laboratory / DC) potentiometer — precision DC potentiometer with dial resistors + slide wire.

Construction: 14–16 step dial resistors (1 V, 0.1 V steps) + 100-division slide wire (0.001 V). Standard cell terminals, unknown terminals, galvanometer, battery + rheostat, selector switches.

Operation:

  1. Standardisation: Connect standard cell (Weston 1.0186 V at 20°C). Adjust working current (rheostat) until galvanometer null at dial =1.0186 V. Now current is correct and dial reads directly in volts.
  2. Measurement: Switch to unknown; balance by dials + slide wire; reading = unknown EMF directly.

Accuracy ±0.02%, range 0–1.6 V (with low/high range switch via voltage divider for higher). Used for calibrating voltmeters, ammeters via standard resistor.

Crompton (laboratory / DC) potentiometer — dial resistors + slide wire સાથે precision DC potentiometer.

બંધારણ: 14–16 step dial resistors (1 V, 0.1 V steps) + 100-division slide wire (0.001 V). Standard cell terminals, unknown terminals, galvanometer, battery + rheostat, selector switches.

કાર્ય:

  1. Standardisation: Standard cell (Weston 20°C પર 1.0186 V) જોડો. Galvanometer dial =1.0186 V પર null બતાવે ત્યાં સુધી working current (rheostat) adjust કરો. હવે current સાચો અને dial સીધું volts માં વાંચે.
  2. Measurement: Unknown પર switch કરો; dials + slide wire થી balance કરો; reading = unknown EMF સીધું.

Accuracy ±0.02%, range 0–1.6 V (વધારે માટે voltage divider થી low/high range switch). Voltmeters, ammeters ને standard resistor દ્વારા calibrate કરવા વપરાય.

Q.2 (c) Explain Kelvin double Bridge. (7 marks)પ્ર.2 (ક) કેલ્વિન ડબલ બ્રિજ સમજાવો. (૦૭ ગુણ)7 marks૦૭ ગુણ

Purpose: Measure very low resistances (µΩ to ~1 Ω) — e.g., winding resistance, bus bars, joints — where lead/contact resistance would swamp Wheatstone bridge.

Why double? Extra ratio arm p/q eliminates the uncertain connecting link resistance r between unknown Rx and standard Rs.

Circuit: Wheatstone outer ratio P/Q, inner ratio p/q with connecting link r. Supply across AB, galvanometer across inner nodes.

Balance condition: PQ = pq   then   Rx = PQ · Rs

General (if not exactly p/q = P/Q): Rx = (P/Q)Rs + p·r/(p+q+r) · (P/Q − p/q). Second term vanishes when ratios equal — keep them equal.

Procedure: Use four-terminal (Kelvin) connections; connect heavy current leads separate from voltage (potential) leads; adjust P/Q and p/q together; balance galvanometer zero; compute Rx.

Errors / precautions: Thermoelectric EMFs (use DC reversal), contact resistance (clean terminals, Kelvin clips), heating (limit current), use proper Rs (low temp-co).

હેતુ: ખૂબ નાના resistances (µΩ થી ~1 Ω) માપવા — દા.ત. winding resistance, bus bars, joints — જ્યાં lead/contact resistance Wheatstone bridge ને ખોટું પાડે.

Double શા માટે? Extra ratio arm p/q unknown Rx અને standard Rs વચ્ચેની uncertain connecting link resistance r ને દૂર કરે.

Circuit: Wheatstone outer ratio P/Q, inner ratio p/q connecting link r સાથે. AB પર supply, inner nodes પર galvanometer.

Balance condition: PQ = pq   ત્યારે   Rx = PQ · Rs

સામાન્ય (જો p/q = P/Q બરાબર ન હોય): Rx = (P/Q)Rs + p·r/(p+q+r) · (P/Q − p/q). બીજો term ratios સમાન રાખતાં zero થાય — સમાન રાખો.

પદ્ધતિ: Four-terminal (Kelvin) connections વાપરો; ભારે current leads ને voltage (potential) leads થી અલગ જોડો; P/Q અને p/q સાથે adjust કરો; galvanometer zero પર balance; Rx ગણો.

ભૂલો / સાવચેતીઓ: Thermoelectric EMFs (DC reversal વાપરો), contact resistance (terminals સાફ, Kelvin clips), heating (current મર્યાદિત), યોગ્ય Rs (ઓછો temp-co) વાપરો.

Q.2 (a) OR Explain De Sauty's Bridge. (3 marks)પ્ર.2 (અ) OR ડી-સાઉટી બ્રિજ સમજાવો. (૦૩ ગુણ)3 marks૦૩ ગુણ

Purpose: Compare two capacitances when losses negligible (ideal / low-loss capacitors). AC bridge with resistors in two arms, capacitors in the other two.

At balance: C1C2 = R2R1   (or C1/C2 = R2/R1) — from impedance balance Z1Z4 = Z2Z3 with Zc=1/jωC.

Supply AC (1kHz typical), detector headphones/vibration galvanometer. Limitation: Not for lossy capacitors (needs resistance balance as well) — modified De Sauty adds resistors in series with capacitors; else use Schering bridge for lossy/dissipation factor.

હેતુ: Losses નજીવા હોય ત્યારે બે capacitances ની તુલના (ideal / low-loss capacitors). AC bridge — બે arms માં resistors, બીજી બે માં capacitors.

Balance પર: C1C2 = R2R1   — impedance balance Z1Z4 = Z2Z3 થી Zc=1/jωC સાથે.

Supply AC (લાક્ષણિક 1kHz), detector headphones/vibration galvanometer. મર્યાદા: Lossy capacitors માટે નહીં (resistance balance પણ જોઈએ) — modified De Sauty capacitors સાથે series માં resistors ઉમેરે; નહીં તો lossy/dissipation factor માટે Schering bridge વાપરો.

Q.2 (b) OR Write types of DC bridges and explain Kelvin Double Bridge. (4 marks)પ્ર.2 (બ) OR ડી.સી. બ્રિજના પ્રકારો લખો અને કેલ્વિન ડબલ બ્રિજ સમજાવો. (૦૪ ગુણ)4 marks૦૪ ગુણ

Types of DC bridges:

  1. Wheatstone bridge — medium resistances (1 Ω to ~1 MΩ): Rx = (P/Q)·Rs.
  2. Kelvin double bridge — low resistances (µΩ–1 Ω) with four-terminal method.
  3. Kelvin–Varley / Carey-Foster — variations for precise medium-low; Megger (bridge ohmmeter) for insulation/high resistance.

Kelvin double bridge (summary for 4M): Adds inner ratio p/q to Wheatstone to cancel link resistance r between Rx and Rs. When outer ratio = inner ratio (P/Q = p/q), balance simplifies to Rx = (P/Q)Rs.

Used for motor winding, cable joint, bus bar resistances; four-terminal (current + potential) connections separate lead resistance.

DC bridges ના પ્રકારો:

  1. Wheatstone bridge — medium resistances (1 Ω થી ~1 MΩ): Rx = (P/Q)·Rs.
  2. Kelvin double bridge — નાના resistances (µΩ–1 Ω) four-terminal method સાથે.
  3. Kelvin–Varley / Carey-Foster — precise medium-low માટે variations; Megger (bridge ohmmeter) insulation/high resistance માટે.

Kelvin double bridge (૦૪ ગુણ માટે ટૂંકમાં): Rx અને Rs વચ્ચે link resistance r ને cancel કરવા Wheatstone માં inner ratio p/q ઉમેરે. જ્યારે outer ratio = inner ratio (P/Q = p/q), balance Rx = (P/Q)Rs માં સરળ બને.

Motor winding, cable joint, bus bar resistances માટે; four-terminal (current + potential) connections lead resistance ને અલગ કરે.

Q.2 (c) OR Explain construction and working of Megger. (7 marks)પ્ર.2 (ક) OR મેગરનું બંધારણ અને કાર્ય સમજાવો. (૦૭ ગુણ)7 marks૦૭ ગુણ

Purpose: Measure insulation resistance (kΩ to thousands of MΩ) at test voltage 250/500/1000 V DC — for cables, motor windings, installations.

Construction:

  • Hand-driven DC generator (or electronic DC-DC converter in modern electronic Megger) — permanent-magnet generator with centrifugal governor/voltage regulator to give stable test voltage despite varying crank speed.
  • Ratio-meter movement: Two coils (current coil + voltage/pressure coil) on same moving system with no controlling spring; deflection ∝ ratio V/I ∝ resistance. Pointer indicates MΩ directly; scale non-linear (∞ at no current).
  • Three terminals: Line (L) to conductor, Earth (E) to earth/sheath, Guard (G) to intercept surface leakage (guard diverts leakage away from current coil → true insulation reads).

Working:

  1. Disconnect supply from equipment; verify dead, discharge residual charge.
  2. Connect L to winding/conductor, E to frame/earth, G to exposed surface if needed.
  3. Crank steadily (120 rpm) or press test on electronic Megger; read insulation value.
  4. For healthy LV equipment: >1 MΩ per kV typically; trending over time matters more than single value.

Precautions: Test dead circuit only; after test, discharge conductor (capacitance may hold charge); guard reduces surface leakage error; avoid damp conditions; correct voltage rating (500V for 415V systems, 1000V for HV).

હેતુ: Insulation resistance (kΩ થી હજારો MΩ) test voltage 250/500/1000 V DC પર માપવું — cables, motor windings, installations માટે.

બંધારણ:

  • Hand-driven DC generator (આધુનિક electronic Megger માં electronic DC-DC converter) — centrifugal governor/voltage regulator સાથે permanent-magnet generator જેથી crank speed બદલાય તો પણ stable test voltage મળે.
  • Ratio-meter movement: બે coils (current coil + voltage/pressure coil) એક જ moving system પર, controlling spring વગર; deflection ∝ V/I ∝ resistance. Pointer સીધું MΩ બતાવે; scale non-linear (કોઈ current નહીં ત્યારે ∞).
  • ત્રણ terminals: Line (L) conductor પર, Earth (E) earth/sheath પર, Guard (G) surface leakage ને intercept કરવા (guard leakage ને current coil થી દૂર લઈ જાય → સાચું insulation વાંચે).

કાર્ય:

  1. Equipment નો supply disconnect કરો; dead છે તે ચકાસો, residual charge discharge કરો.

Q.3 (b) Explain about a range extension of ammeter. (4 marks)પ્ર.3 (બ) એમીટરની રેન્જ એક્સ્ટેન્શન વિશે સમજાવો. (૦૪ ગુણ)4 marks૦૪ ગુણ

Need: Basic meter movement carries only small current (mA) and has internal resistance. To measure larger current, bypass most current via low resistance.

Q.3 (c) Explain moving iron type ammeter. (7 marks)પ્ર.3 (ક) મૂવિંગ આયર્ન પ્રકારનો એમીટર સમજાવો. (૦૭ ગુણ)7 marks૦૭ ગુણ

Principle: Iron piece in magnetic field of fixed coil experiences force tending to increase flux linkage. Torque ∝ I² (independent of direction) → works AC & DC, RMS reading.

Attraction type: Single soft-iron disc/vane attracted into hollow fixed coil against spring control. Scale cramped at start (deflection ∝ I²).

Repulsion type (more common): Two soft-iron pieces inside coil, magnetised alike → repel. One fixed, one on moving spindle → repulsion torque moves pointer vs spring + air-damping vane.

Construction: Fixed coil (current-carrying), moving iron(s), spindle with pointer, control springs (or gravity weights), air dashpot (piston/vane) or eddy damping.

Characteristics: Rugged, cheap, wide range (mA to kA with shunts/CTs), works both AC/DC, withstand overload. Errors: hysteresis (different DC up/down, minimise with mumetal), stray magnetic field (shield), frequency (eddy, inductance limits ~100Hz), temperature.

Calibration with DC and AC standards; scale non-linear but can be shaped by iron profile.

સિદ્ધાંત: Fixed coil ના magnetic field માં iron piece flux linkage વધારવાની દિશામાં બળ અનુભવે. Torque ∝ I² (દિશા પર આધાર નહીં) → AC & DC બંને પર કામ, RMS reading.

Attraction type: Single soft-iron disc/vane hollow fixed coil માં spring control સામે ખેંચાય. Scale શરૂઆતમાં ગીચ (deflection ∝ I²).

Repulsion type (વધુ સામાન્ય): Coil અંદર બે soft-iron pieces એક સરખું magnetised → repel. એક fixed, એક moving spindle પર → repulsion torque pointer ને spring + air-damping vane સામે ખસેડે.

બંધારણ: Fixed coil (current વહન), moving iron(s), pointer સાથે spindle, control springs (અથવા gravity weights), air dashpot (piston/vane) અથવા eddy damping.

લાક્ષણિકતા: મજબૂત, સસ્તું, wide range (shunts/CTs સાથે mA થી kA), AC/DC બંને, overload સહન. ભૂલો: hysteresis (DC up/down અલગ, mumetal થી ઘટાડો), stray magnetic field (shield), frequency (eddy, inductance ~100Hz સુધી મર્યાદા), temperature.

DC અને AC standards સાથે calibration; scale non-linear પણ iron profile થી shape આપી શકાય.

Q.3 (a) OR Draw a diagram of Clamp on meter and explain its working. (3 marks)પ્ર.3 (અ) OR ક્લેમ્પ-ઓન મીટરની આકૃતિ દોરો અને તેનું કાર્ય સમજાવો. (૦૩ ગુણ)3 marks૦૩ ગુણ

What it is: Current transformer with split (hinged) core that clamps around a single conductor — measurement without breaking circuit.

શું છે: Split (hinged) core સાથે current transformer જે એક conductor ને clamp કરે — circuit તોડ્યા વગર માપન.

કાર્ય: Conductor = 1 turn નો primary. Split-core CT (ferrite) તેને ઘેરે; secondary core પર વીંટળાયેલ ammeter/rectifier + display ને feed કરે. Load current થી magnetic flux secondary માં primary ના પ્રમાણમાં current induce કરે (I1/N2). DC clamp માટે Hall-effect / flux-gate sensor CT induction ની જગ્યાએ આવે.

ઉપયોગ: Motors, panels પર ઝડપી AC load current તપાસ (kA સુધી); સલામત (insulated jaws). Conductor ને વચ્ચે રાખો, નજીકના magnetic fields ટાળો, સાચો range પસંદ કરો.

Q.3 (b) OR Explain PMMC type voltmeter. (4 marks)પ્ર.3 (બ) OR PMMC પ્રકારનો વૉલ્ટમીટર સમજાવો. (૦૪ ગુણ)4 marks૦૪ ગુણ

Q.3 (c) OR Explain 3-phase power measurement using two watt-meter. (7 marks)પ્ર.3 (ક) OR બે વોટમીટરથી 3-ફેઝ પાવર માપન સમજાવો. (૦૭ ગુણ)7 marks૦૭ ગુણ

Applicable: 3-wire 3-phase (balanced or unbalanced, star or delta) — two wattmeters with current coils in two lines, pressure coils between those lines and the third line (no neutral needed).

Connections: W1: current in R, voltage R–Y; W2: current in B, voltage B–Y (or R,Y / Y,B pairs). Modern electronic meters implement equivalently.

W1 = VLIL cos(30°−φ)   ;   W2 = VLIL cos(30°+φ)   (for balanced load, φ = load angle)
Total active power P = W1+W2 = √3 VLIL cosφ
Reactive: W1−W2 = VLIL sinφ   →   tanφ = √3 W1−W2W1+W2 ;   pf = cosφ

Readings: φ=0° → W1=W2; φ=30° → W2=0; φ=60° → W2=0; φ>60° → one wattmeter reverses (swap voltage/current coil to read negative, subtract). Zero power factor? Not balanced alone.

Advantage: Only two meters, no neutral, works for unbalanced (Blondel's theorem) with total P still W1+W2.

લાગુ: 3-wire 3-phase (balanced અથવા unbalanced, star અથવા delta) — બે wattmeters, current coils બે lines માં, pressure coils તે lines અને ત્રીજી line વચ્ચે (neutral જરૂરી નથી).

Connections: W1: R માં current, voltage R–Y; W2: B માં current, voltage B–Y (અથવા R,Y / Y,B pairs). આધુનિક electronic meters સમકક્ષ રીતે કરે.

W1 = VLIL cos(30°−φ)   ;   W2 = VLIL cos(30°+φ)   (balanced load માટે, φ = load angle)
કુલ active power P = W1+W2 = √3 VLIL cosφ
Reactive: W1−W2 = VLIL sinφ   →   tanφ = √3 W1−W2W1+W2 ;   pf = cosφ

Readings: φ=0° → W1=W2; φ=30° → W2=0; φ=60° → W2=0; φ>60° → એક wattmeter reverse (negative વાંચવા voltage/current coil અદલાબદલી, બાદ કરો). Zero power factor? Balanced એકલો નહીં.

ફાયદો: માત્ર બે meters, neutral નહીં, unbalanced માટે પણ કામ (Blondel's theorem) — total P હજુ W1+W2.

Q.4 (a) Draw figure of analog type energy meter and explain its working. (3 marks)પ્ર.4 (અ) એનાલોગ પ્રકારના એનર્જી મીટરની આકૃતિ દોરો અને તેનું કાર્ય સમજાવો. (૦૩ ગુણ)3 marks૦૩ ગુણ

Single-phase induction energy meter: Two electromagnets (shunt = pressure coil ∝ V across supply, series = current coil ∝ I in line) produce alternating fluxes 90° apart via shading bands; they induce eddy currents in light aluminium disc → torque ∝ power (VI cosφ).

Disc + brake magnet + register: Eddy currents interact with permanent brake magnet → damping torque ∝ speed. At equilibrium disc speed ∝ power; revolutions ∝ energy (kWh). Gear train counts disc revolutions → dials/kWh display. Friction compensating loop and creep holes provided.

Single-phase induction energy meter: બે electromagnets (shunt = pressure coil ∝ supply પર V, series = current coil ∝ line માં I) shading bands દ્વારા 90° અંતરે alternating fluxes ઉત્પન્ન કરે; હળવા aluminium disc માં eddy currents induce કરે → torque ∝ power (VI cosφ).

Q.4 (b) Explain a calibration of watt-meter. (4 marks)પ્ર.4 (બ) વૉટમીટરનું કેલિબ્રેશન સમજાવો. (૦૪ ગુણ)4 marks૦૪ ગુણ

Calibration (comparison with standard): Test wattmeter (Wtest) compared with standard wattmeter (Wstd) or phantom method with standard voltmeter + ammeter + phase meter: Ptrue=VI cosφ.

  1. Connect both wattmeters to same voltage (via auto-transformer) and same current (via loading rheostat / phantom loading with separate low current + low voltage to save power).
  2. Vary load current and power factor (R/L/C or phase shifter: unity, 0.5 lag/lead, low pf).
  3. At each point record Wtest vs Wstd; compute error = (Wtest−Wstd)/Wstd ×100% and correction = −error.
  4. Adjust wattmeter (spring tension, magnetic shunt) if adjustable; else apply correction table for field use.

Precautions: Stable supply, correct pressure/current coil polarity, allow warm-up, avoid stray fields, use same frequency.

કેલિબ્રેશન (standard સાથે comparison): Test wattmeter (Wtest) ને standard wattmeter (Wstd) અથવા standard voltmeter + ammeter + phase meter થી phantom method: Ptrue=VI cosφ સાથે સરખાવો.

  1. બંને wattmeters ને એક જ voltage (auto-transformer દ્વારા) અને એક જ current (loading rheostat / phantom loading — અલગ ઓછો current + ઓછો voltage power બચાવવા) સાથે જોડો.
  2. Load current અને power factor (R/L/C અથવા phase shifter: unity, 0.5 lag/lead, low pf) બદલો.
  3. દરેક point પર Wtest vs Wstd નોંધો; error = (Wtest−Wstd)/Wstd ×100% અને correction = −error ગણો.
  4. Adjustable હોય તો wattmeter (spring tension, magnetic shunt) adjust કરો; નહીં તો field use માટે correction table લાગુ કરો.

સાવચેતીઓ: સ્થિર supply, સાચી pressure/current coil polarity, warm-up સમય આપો, stray fields ટાળો, એ જ frequency વાપરો.

  1. Connect test meter and standard meter in series (same V, I, pf via variac + loading + phase shifter).
  2. For a measured number of disc revolutions (e.g., 10) or a known time, record energy by standard (Est) and by test meter (Et = count × meter constant).
  3. Error = (Et − Est)/Est ×100%. Test at rated voltage ±2%, rated frequency, at currents 5%, 25%, 50%, 100%, 200% Ib and at unity + 0.5 lag pf.
  4. Adjust brake magnet position (eddy damping) or electronic calibration constant; if not adjustable, issue correction table. Check creep (no-load with voltage only) and starting current.

કેલિબ્રેશન (standard/sub-standard energy meter અથવા DC phantom method સામે):

  1. Test meter અને standard meter ને series માં જોડો (એ જ V, I, pf variac + loading + phase shifter દ્વારા).
  2. માપેલ disc revolutions (દા.ત. 10) અથવા જાણીતા સમય માટે standard થી energy (Est) અને test meter થી energy (Et = count × meter constant) નોંધો.
  3. Error = (Et − Est)/Est ×100%. Rated voltage ±2%, rated frequency, currents 5%, 25%, 50%, 100%, 200% Ib અને unity + 0.5 lag pf પર test કરો.
  4. Brake magnet position (eddy damping) અથવા electronic calibration constant adjust કરો; adjustable ન હોય તો correction table આપો. Creep (માત્ર voltage સાથે no-load) અને starting current તપાસો.
Q.4 (c) OR Explain phase sequence indicator. (7 marks)પ્ર.4 (ક) OR ફેઝ સિક્વન્સ ઇન્ડિકેટર સમજાવો. (૦૭ ગુણ)7 marks૦૭ ગુણ

Purpose: Determine phase order (R→Y→B vs R→B→Y) of 3-phase supply — essential for motor rotation direction, transformer paralleling, correct metering.

Types:

  1. Rotating (induction-disc) type: Miniature 3-phase induction motor with three coils (R,Y,B). Correct sequence RYB → disc rotates clockwise (marked arrow); reverse RBY → anti-clockwise. Self-starting, clear indication, needs 3-phase supply.
  2. Static (lamp + capacitor) type: Two lamps + capacitor in star; unbalanced bridge creates unequal voltages on lamps per sequence. RYB → lamp A bright, B dim; RBY → opposite. No moving parts, cheap, needs neutral/reference; sensitive to voltage imbalance.

Procedure: Connect three leads to supply (ensure dead before connecting); energise; observe rotation or lamp brightness; label phases. Verify with known supply first.

Wrong sequence → 3-phase motor reverses (swap any two phases to correct); metering errors in KWh if CT polarity wrong.

હેતુ: 3-phase supply નો phase order (R→Y→B vs R→B→Y) નક્કી કરવો — motor rotation direction, transformer paralleling, સાચી metering માટે જરૂરી.

પ્રકારો:

  1. Rotating (induction-disc) type: ત્રણ coils (R,Y,B) સાથે નાનો 3-phase induction motor. સાચો sequence RYB → disc clockwise (marked arrow) ફરે; reverse RBY → anti-clockwise. Self-starting, સ્પષ્ટ indication, 3-phase supply જોઈએ.
  2. Static (lamp + capacitor) type: Star માં બે lamps + capacitor; unbalanced bridge sequence પ્રમાણે lamps પર અસમાન voltages બનાવે. RYB → lamp A bright, B dim; RBY → ઉલટું. Moving parts નહીં, સસ્તું, neutral/reference જોઈએ; voltage imbalance પ્રત્યે sensitive.

પદ્ધતિ: ત્રણ leads ને supply પર જોડો (જોડતા પહેલાં dead ખાતરી કરો); energise કરો; rotation અથવા lamp brightness જુઓ; phases label કરો. પહેલાં જાણીતા supply સાથે verify કરો.

ખોટો sequence → 3-phase motor reverse થાય (સાચો કરવા કોઈપણ બે phases અદલાબદલી કરો); CT polarity ખોટી હોય તો KWh metering માં ભૂલો.

Q5 · Transducers and sensorsપ્ર.5 · ટ્રાન્સડ્યુસર અને સેન્સર

Q.5 (a) Define transducer, Electrical Transducer, Proximity sensor. (3 marks)પ્ર.5 (અ) વ્યાખ્યા આપો: ટ્રાન્સડ્યુસર, ઇલેક્ટ્રિકલ ટ્રાન્સડ્યુસર અને પ્રોક્સિમિટી સેન્સર. (૦૩ ગુણ)3 marks૦૩ ગુણ

Transducer: Device that converts one form of energy/quantity into another (measurand → usable signal). Example: thermocouple (heat → mV), LVDT (displacement → AC voltage).

Electrical transducer: Transducer whose output is electrical (voltage, current, resistance, inductance, capacitance, frequency) suitable for display/control. Example: RTD (temperature → resistance), strain gauge (force → resistance change).

Proximity sensor: Sensor that detects presence/position of an object within close range without physical contact, using electromagnetic/capacitive/optical fields. Example: inductive proximity (metal detection), capacitive (any dielectric), optical (light interruption). Output is switching (ON/OFF) or analog distance.

Transducer (ટ્રાન્સડ્યુસર): એક સ્વરૂપની energy/quantity ને બીજા સ્વરૂપમાં ફેરવતું device (measurand → ઉપયોગી signal). ઉદા.: thermocouple (heat → mV), LVDT (displacement → AC voltage).

Electrical transducer (ઇલેક્ટ્રિકલ ટ્રાન્સડ્યુસર): જેનો output electrical હોય (voltage, current, resistance, inductance, capacitance, frequency) — display/control માટે યોગ્ય. ઉદા.: RTD (temperature → resistance), strain gauge (force → resistance change).

Proximity sensor (પ્રોક્સિમિટી સેન્સર): નજીકના range માં વસ્તુની હાજરી/position ને physical contact વગર electromagnetic/capacitive/optical fields વડે શોધતો sensor. ઉદા.: inductive proximity (metal detection), capacitive (કોઈપણ dielectric), optical (light interruption). Output switching (ON/OFF) અથવા analog distance હોય.

Q.5 (b) Explain pizo-electric transducer. (4 marks)પ્ર.5 (બ) પીઝો-ઇલેક્ટ્રિક ટ્રાન્સડ્યુસર વિશે સમજાવો. (૦૪ ગુણ)4 marks૦૪ ગુણ

Principle (piezoelectric effect): Certain crystals (quartz, Rochelle salt, PZT ceramic, PVDF) develop electric charge/potential when mechanically stressed (direct effect); conversely they strain when voltage applied (converse, for actuators). Polarisation changes create surface charge proportional to force.

Generated charge Q = d · F   ;   Output voltage V = Q / Ccrystal   (d = piezo constant, e.g., quartz d11≈2.3 pC/N)

Features: Self-generating (active), high sensitivity, wide frequency response (Hz to MHz), small, rugged — but charge leaks through finite internal resistance → not suitable for true static (DC) measurement without special charge amplifier with long time constant.

Applications: Dynamic force, pressure (engine indicators), accelerometers (seismic mass on crystal), ultrasonic transmitters, knock sensors, microphones.

સિદ્ધાંત (piezoelectric effect): અમુક crystals (quartz, Rochelle salt, PZT ceramic, PVDF) mechanically stress થતાં electric charge/potential ઉત્પન્ન કરે (direct effect); ઉલટું voltage આપતાં strain થાય (converse, actuators માટે). Polarisation બદલાતા surface charge force ના પ્રમાણમાં બને.

Generated charge Q = d · F   ;   Output voltage V = Q / Ccrystal   (d = piezo constant, દા.ત. quartz d11≈2.3 pC/N)

લાક્ષણિકતા: Self-generating (active), વધુ sensitivity, wide frequency response (Hz થી MHz), નાનું, મજબૂત — પણ finite internal resistance દ્વારા charge leak થાય → ખાસ charge amplifier વગર સાચા static (DC) માપન માટે યોગ્ય નહીં.

ઉપયોગો: Dynamic force, pressure (engine indicators), accelerometers (crystal પર seismic mass), ultrasonic transmitters, knock sensors, microphones.

Q.5 (c) Explain LVDT with neat diagram. (7 marks)પ્ર.5 (ક) સ્વચ્છ આકૃતિ સાથે LVDT સમજાવો. (૦૭ ગુણ)7 marks૦૭ ગુણ

Construction: Cylindrical former with primary coil in centre, two identical secondaries on either side (wound opposite/concentric). Movable high-permeability iron core (connected to measurand) slides inside without contact. Primary excited by AC (1–10 kHz, few volts).

Working: Primary flux links both secondaries. When core centred, induced voltages V1 = V2 (symmetry) but opposite series → net output Vout = V1−V2 = 0 (null). Displace core by x → coupling to one secondary increases, other decreases → differential output magnitude ∝ |x|, phase (0° or 180° relative to excitation) indicates direction.

Vout = K · x   (linear range, typically ±2 to ±100 mm depending on size)

Signal conditioning: Secondary differential → phase-sensitive demodulator → DC proportional to displacement with sign.

Features: Contactless, infinite resolution, low hysteresis, high repeatability, rugged, long life; sensitivity ~10–50 mV/mm/V excitation; linearity ~0.25%. Applications: position, thickness, pressure (diaphragm → core), vibration.

બંધારણ: વચ્ચે primary coil, બંને બાજુ બે સમાન secondaries (વિરુદ્ધ/concentric wound) સાથે cylindrical former. માપવાની વસ્તુ સાથે જોડેલ movable high-permeability iron core અંદર contact વગર સરકે. Primary ને AC (1–10 kHz, થોડા volts) થી excite કરાય.

કાર્ય: Primary flux બંને secondaries ને link કરે. Core વચ્ચે હોય ત્યારે induced voltages V1 = V2 (symmetry) પણ વિરુદ્ધ series → net output Vout = V1−V2 = 0 (null). Core ને x ખસેડો → એક secondary સાથે coupling વધે, બીજા સાથે ઘટે → differential output magnitude ∝ |x|, phase (excitation સામે 0° અથવા 180°) દિશા બતાવે.

Vout = K · x   (linear range, size પ્રમાણે સામાન્ય રીતે ±2 થી ±100 mm)

Signal conditioning: Secondary differential → phase-sensitive demodulator → displacement ના પ્રમાણમાં sign સાથે DC.

લાક્ષણિકતા: Contactless, infinite resolution, ઓછો hysteresis, વધુ repeatability, મજબૂત, લાંબી life; sensitivity ~10–50 mV/mm/V excitation; linearity ~0.25%. ઉપયોગો: position, thickness, pressure (diaphragm → core), vibration.

Q.5 (b) OR Explain photo coupler, opto-coupler, and opto-isolator with neat diagram. (4 marks)પ્ર.5 (બ) OR ફોટો કપલર, ઓપ્ટો કપલર અને ઓપ્ટો આઇસોલેટર સ્વચ્છ આકૃતિ સાથે સમજાવો. (૦૪ ગુણ)4 marks૦૪ ગુણ

Same device, three names (optical coupling): Input light source (LED / IR LED) optically coupled to output photosensor (phototransistor, photodiode, TRIAC) within opaque package — electrical isolation between input and output circuits.

Types:

  • Photo-coupler / opto-coupler: LED → phototransistor (DC switching, isolation 2–5kV). Example: PC817 for PLC input isolation.
  • Opto-isolator (high-isolation): Emphasises isolation rating (5–10kV) for safety between HV measurement and LV electronics.
  • Opto-TRIAC / solid-state relay: LED → photo-TRIAC for AC load switching with zero-cross.

Working: Input current lights LED → photons cross transparent barrier → phototransistor conducts → output changes state, with no galvanic connection. CTR (current transfer ratio) defines gain.

Use: Isolate noisy/HT circuits from microcontroller, level shift, feedback in switch-mode supplies, PLC I/O isolation.

એક જ device, ત્રણ નામ (optical coupling): Input light source (LED / IR LED) opaque package અંદર output photosensor (phototransistor, photodiode, TRIAC) સાથે optically coupled — input અને output circuits વચ્ચે electrical isolation.

પ્રકારો:

  • Photo-coupler / opto-coupler: LED → phototransistor (DC switching, isolation 2–5kV). ઉદા.: PLC input isolation માટે PC817.
  • Opto-isolator (high-isolation): Isolation rating (5–10kV) પર ભાર — HV measurement અને LV electronics વચ્ચે safety માટે.
  • Opto-TRIAC / solid-state relay: LED → photo-TRIAC AC load switching માટે zero-cross સાથે.

કાર્ય: Input current LED પ્રગટાવે → photons transparent barrier પાર કરે → phototransistor conduct કરે → output state બદલાય, galvanic connection વગર. CTR (current transfer ratio) gain વ્યાખ્યાયિત કરે.

ઉપયોગ: Noisy/HT circuits ને microcontroller થી isolate કરવા, level shift, switch-mode supplies માં feedback, PLC I/O isolation.

Q.5 (c) OR Explain capacitive type proximity sensor. (7 marks)પ્ર.5 (ક) OR કેપેસિટિવ પ્રકારનો પ્રોક્સિમિટી સેન્સર સમજાવો. (૦૭ ગુણ)7 marks૦૭ ગુણ

Principle: Sensing electrode and ground (or second electrode) form a capacitor C = εA/d (ε = effective permittivity of medium between). Any target (metal, plastic, glass, liquid, wood) entering field changes ε or effective distance → C changes.

Construction: Oscillator (RC or LC) whose frequency/amplitude depends on sensing capacitance + internal reference; rectifier/detector → comparator with adjustable threshold (sensitivity pot) → transistor/relay output (NO/NC) with LED indicator. Guard electrode reduces stray sensitivity.

Working:

  1. No target: C = C0 → oscillator at nominal frequency/amplitude → comparator below threshold → output OFF.
  2. Target approaches (few mm to ~50mm): C increases → oscillator frequency shifts / amplitude dampens → detector exceeds threshold → output ON. Effective for non-metals because εr >1 (εr≈80 for water → very sensitive to liquids).
  3. Hysteresis built in to avoid chattering.

Features: Detects any dielectric (advantage over inductive which only metals); adjustable sensing distance via pot; short range (10–40mm typical); affected by humidity/dust (needs cleaning), temperature.

Applications: Level detection (liquid in non-metallic tank), material presence on conveyor, paper/wood counting, touch switches.

સિદ્ધાંત: Sensing electrode અને ground (અથવા બીજો electrode) capacitor C = εA/d બનાવે (ε = વચ્ચેના medium ની effective permittivity). કોઈપણ target (metal, plastic, glass, liquid, wood) field માં આવતાં ε અથવા effective distance બદલાય → C બદલાય.

બંધારણ: Oscillator (RC અથવા LC) જેની frequency/amplitude sensing capacitance + internal reference પર આધારિત; rectifier/detector → adjustable threshold (sensitivity pot) સાથે comparator → transistor/relay output (NO/NC) LED indicator સાથે. Guard electrode stray sensitivity ઘટાડે.

કાર્ય:

  1. Target નહીં: C = C0 → oscillator nominal frequency/amplitude પર → comparator threshold થી નીચે → output OFF.
  2. Target નજીક આવે (થોડા mm થી ~50mm): C વધે → oscillator frequency shift / amplitude damp → detector threshold થી ઉપર → output ON. εr >1 હોવાથી non-metals માટે પણ અસરકારક (પાણી માટે εr≈80 → liquids પ્રત્યે ખૂબ sensitive).
  3. Chattering ટાળવા hysteresis રાખેલ.

લાક્ષણિકતા: કોઈપણ dielectric શોધે (inductive કરતાં ફાયદો જે માત્ર metals); pot થી adjustable sensing distance; ટૂંકો range (લાક્ષણિક 10–40mm); humidity/dust થી અસર (સફાઈ જોઈએ), temperature.

ઉપયોગો: Level detection (non-metallic tank માં liquid), conveyor પર material presence, paper/wood counting, touch switches.

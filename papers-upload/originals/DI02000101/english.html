Q1 · Python basics and strings

Define Python identifiers and variables with examples.3 marks

Question: Define Python identifiers and variables with examples.

An identifier is a name used for a variable, function, class, module or other object. It may contain letters, digits and underscores; it cannot begin with a digit, contain spaces or punctuation, or be a Python keyword. Identifiers are case-sensitive.

Valid: roll_no, _count, total2. Invalid: 2nd, total marks, class.

A variable is a name bound to an object/value. Python creates it on assignment; no declaration or fixed type is required (dynamic typing).

Python

age = 18
name = "Riya"
score = 82.5
age = "eighteen"  # the name can refer to a different type
print(name, score, age)

Write a Python program to check whether a number is prime or not.7 marks

Question: Write a Python program to check whether a number is prime or not.

A prime number is an integer greater than 1 with exactly two positive divisors, 1 and itself. It is enough to test possible divisors up to the square root of n.

Python

from math import isqrt

number = int(input("Enter an integer: "))
if number < 2:
    prime = False
else:
    prime = True
    for divisor in range(2, isqrt(number) + 1):
        if number % divisor == 0:
            prime = False
            break

if prime:
    print(number, "is prime")
else:
    print(number, "is not prime")

For example, 29 is prime; 1, 0 and negative integers are not prime.

Explain identity and membership operators with short examples.3 marks

Question: Explain identity and membership operators with short examples.

Membership operators: in is true when a value is present in a sequence/collection; not in is true when it is absent. For dictionaries, membership tests keys.

Identity operators: is and is not test whether two names refer to the same object, not whether their values are equal. Use == for value equality and the idiom x is None to test for None.

Python

a = [1, 2, 3]
b = a
c = [1, 2, 3]
print(2 in a)       # True
print(9 not in a)   # True
print(a is b)       # True: same object
print(a == c)       # True: equal values
print(a is c)       # False: different objects
print("id" in {"id": 10})  # True: dictionary key

Write a Python program using a recursive function to find the factorial of a number. Show sample input and output.7 marks

Question: Write a Python program using a recursive function to find the factorial of a number. Show sample input and output.

Factorial is defined by 0! = 1 and n! = n × (n−1)! for n > 0. The base case stops recursion; the recursive case reduces n. Factorial is not defined for negative integers.

Python

def factorial(n):
    if n == 0:              # base case
        return 1
    return n * factorial(n - 1)  # recursive case

number = int(input("Enter a non-negative integer: "))
if number < 0:
    print("Factorial is not defined for negative integers.")
else:
    print(f"Factorial of {number} = {factorial(number)}")

Sample run:
Enter a non-negative integer: 5
Factorial of 5 = 120

Question: Write a Python program to open a file and count the number of characters, words, and lines in it.

Read the text once. len(text) counts characters including spaces and newline characters; split() separates whitespace-delimited words; splitlines() counts lines. An empty file produces zero for each count.

Python

filename = input("Enter file name: ")
try:
    with open(filename, "r", encoding="utf-8") as file:
        text = file.read()

    characters = len(text)
    words = len(text.split())
    lines = len(text.splitlines())

    print("Characters:", characters)
    print("Words:", words)
    print("Lines:", lines)
except OSError as error:
    print("Could not read file:", error)

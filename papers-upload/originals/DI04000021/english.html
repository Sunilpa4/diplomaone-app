Q.1 (b) List different types of operators in Java, Explain Arithmetic Operator in detail with example.4 marks

Question as printed: Q.1 (b) List different types of operators in Java, Explain Arithmetic Operator in detail with example.

Java operator groups include arithmetic (+, −, *, /, %), unary (++ , --, +, −, !, ~), relational (==, !=, <, >, <=, >=), logical (&&, ||, !), bitwise (&, |, ^, ~), shift (<<, >>, >>>), assignment (= and compound assignments), conditional (?:), and type comparison (instanceof).

Arithmetic operators perform numeric calculations. + addition, - subtraction, * multiplication, / division and % remainder. When both operands of / are integers, the fractional part is discarded; use a floating-point operand for a decimal result. + also concatenates strings.

Java

public class ArithmeticOperatorsDemo {

        System.out.println((double) a / b); // 3.4
    }

For integer operands, division or remainder by zero throws ArithmeticException. Operator precedence and parentheses determine evaluation order.

Q.1 (c) Write a program in Java to find sum and average of an array element.7 marks

Question as printed: Q.1 (c) Write a program in Java to find sum and average of an array element.

The program traverses a non-empty integer array once. It accumulates the values in a long to reduce overflow risk, then converts the sum to double before division so the average can include a fraction.

Java

public class ArraySumAverage {
    public static void main(String[] args) {
        int[] values = {12, 18, 20, 25, 30};
        if (values.length == 0) {
            System.out.println("Array is empty");
            return;
        }

        long sum = 0;
        for (int value : values) {
            sum += value;
        }
        double average = (double) sum / values.length;

        System.out.println("Sum = " + sum);
        System.out.println("Average = " + average);
    }
}

For this data, sum = 105 and average = 21.0. Casting before division avoids integer truncation.

Q.1 (c) OR Write a program in Java to add two 3*3 matrices.7 marks

Question as printed: Q.1 (c) OR Write a program in Java to add two 3*3 matrices.

Matrix addition adds corresponding elements. Both matrices must have the same dimensions; the two 3×3 arrays below meet that condition.

Java

public class MatrixAddition {
    public static void main(String[] args) {
        int[][] a = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        int[][] b = {
            {9, 8, 7},
            {6, 5, 4},
            {3, 2, 1}
        };
        int[][] sum = new int[3][3];

        for (int row = 0; row < 3; row++) {
            for (int col = 0; col < 3; col++) {
                sum[row][col] = a[row][col] + b[row][col];
            }
        }

        for (int[] row : sum) {
            for (int value : row) {
                System.out.print(value + " ");
            }
            System.out.println();
        }
    }
}

The result is three rows of 10 10 10. The nested loops visit every row/column position exactly once.

Q2 · OOP principles, methods and strings

Q.2 (a) Explain any Three Principals of Object-Oriented Programming.3 marks

Question as printed: Q.2 (a) Explain any Three Principals of Object-Oriented Programming.

The four commonly stated principles are abstraction, encapsulation, inheritance and polymorphism. Any three are:

  • Encapsulation: combine data and methods in a class and control access (often with private fields and public methods). A bank account exposes deposit/withdraw operations rather than allowing arbitrary balance changes.
  • Inheritance: derive a new class from an existing class to reuse and extend behaviour, for example Dog extends Animal.
  • Polymorphism: one interface or superclass reference can invoke different implementations; an overridden method is selected at run time according to the actual object.

Abstraction is another key principle: expose essential operations while hiding implementation details, such as calling pay() without depending on the internal payment process.

Q.2 (b) Explain Method Overloading with example.4 marks

Question as printed: Q.2 (b) Explain Method Overloading with example.

Method overloading means declaring methods in the same class with the same name but different parameter lists (different number, types or order of parameters). The compiler chooses the applicable overload from the arguments at compile time. A different return type alone is not enough to overload a method.

Java

class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}

class OverloadDemo {
    public static void main(String[] args) {
        Calculator c = new Calculator();
        System.out.println(c.add(2, 3));          // 5
        System.out.println(c.add(2.5, 3.1));      // 5.6
        System.out.println(c.add(1, 2, 3));       // 6
    }
}

Overloading is compile-time polymorphism; it provides one meaningful operation for several parameter forms.

Q.2 (a) OR Explain “static” keyword with example.3 marks

Question as printed: Q.2 (a) OR Explain “static” keyword with example.

static declares a class-level member shared by the class rather than a separate copy per object. A static variable has one shared value; a static method can be called with the class name without creating an object and cannot use this or directly access instance members.

Java

class Counter {
    private static int count = 0;

    Counter() {
        count++;
    }

    static int getCount() {
        return count;
    }
}

class StaticDemo {
    public static void main(String[] args) {
        new Counter();
        new Counter();
        System.out.println(Counter.getCount()); // 2
    }
}

Static initialization blocks can initialize class-level data when the class is initialized. The main method is static so the JVM can invoke it without first constructing the application class.

Q.2 (b) OR Explain Constructor Overloading with example.4 marks

Question as printed: Q.2 (b) OR Explain Constructor Overloading with example.

A constructor initializes a new object. It has the class name and no return type. Constructor overloading supplies multiple constructors with different parameter lists so an object can be initialized in different ways. If no constructor is declared, Java provides a no-argument default constructor; once any constructor is declared, that implicit constructor is not supplied.

Java

class Box {
    double length;
    double width;

    Box() {
        this(1.0, 1.0);          // delegate to another constructor
    }

    Box(double side) {
        this(side, side);
    }

    Box(double length, double width) {
        this.length = length;
        this.width = width;
    }

    double area() {
        return length * width;
    }
}

class ConstructorDemo {
    public static void main(String[] args) {
        System.out.println(new Box().area());        // 1.0
        System.out.println(new Box(4).area());       // 16.0
        System.out.println(new Box(4, 3).area());    // 12.0
    }
}

The call to this(...) must be the first statement in a constructor.

Q.2 (c) OR Write a JAVA program that demonstrate Use of Access Modifiers.7 marks

Question as printed: Q.2 (c) OR Write a JAVA program that demonstrate Use of Access Modifiers.

Java access modifiers control where classes and members can be accessed. The example uses two packages to demonstrate public, protected, package-private (no modifier) and private.

Java

// File: p1/Base.java
package p1;
public class Base {
    public int publicValue = 1;
    protected int protectedValue = 2;
    int packageValue = 3;            // package-private
    private int privateValue = 4;

    public int getPrivateValue() {   // controlled access
        return privateValue;
    }
}

// File: p2/Child.java
package p2;
import p1.Base;
public class Child extends Base {
    public void show() {
        System.out.println(publicValue);      // accessible
        System.out.println(protectedValue);   // accessible in subclass
        // packageValue and privateValue are not accessible here
    }
}

// File: p2/Main.java
package p2;
import p1.Base;
public class Main {
    public static void main(String[] args) {
        Base b = new Base();
        System.out.println(b.publicValue);
        System.out.println(b.getPrivateValue());
        new Child().show();
    }
}

protectedYesYesYes, through inheritanceNo
package-privateYesYesNoNo
privateYesNoNoNo

The protected cross-package access is available in subclass code under Java’s inheritance access rules; it is not general public access.

Q.3 (a) Explain Wrapper Class with example.3 marks

Question as printed: Q.3 (a) Explain Wrapper Class with example.

A wrapper class represents a primitive value as an object. Java provides Byte, Short, Integer, Long, Float, Double, Character and Boolean. Wrappers are useful with generic collections, which store objects, and provide parsing and conversion methods.

Java

public class WrapperDemo {

Q.3 (b) Explain Single Inheritance with example.4 marks

Question as printed: Q.3 (b) Explain Single Inheritance with example.

Single inheritance occurs when one subclass extends one superclass. The subclass inherits accessible fields and methods and can add or override behaviour. Java supports one direct superclass for a class.

Java

class Animal {
    void eat() {
        System.out.println("Animal eats");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}

public class InheritanceDemo {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();    // inherited from Animal
        d.bark();   // defined in Dog
    }
}

Here Animal is the superclass and Dog is its subclass. Constructors are not inherited, although a subclass constructor can call a superclass constructor.

Q.3 (c) Write a program in Java to demonstrate use of “super” keyword.7 marks

Question as printed: Q.3 (c) Write a program in Java to demonstrate use of “super” keyword.

super refers to the superclass part of the current object. It can call a superclass constructor, access an inherited member hidden by a subclass member, or invoke an overridden superclass method.

Java

class Vehicle {
    String type;

    Vehicle(String type) {
        this.type = type;
    }

    void display() {
        System.out.println("Vehicle type: " + type);
    }
}

class Car extends Vehicle {
    String type = "Car";

    Car() {
        super("Motor vehicle");  // superclass constructor; first statement
    }

    @Override
    void display() {
        super.display();          // superclass method
        System.out.println("Specific type: " + this.type);
        System.out.println("Parent field: " + super.type);
    }
}

public class SuperDemo {
    public static void main(String[] args) {
        new Car().display();
    }
}

super(...) must be the first constructor statement. A constructor may call either this(...) or super(...) explicitly, not both.

Question as printed: Q.3 (a) OR How to Take User Input in Java by Using Scanner Class? Explain with example.

Scanner from java.util reads formatted input from sources such as System.in. Use methods such as nextInt(), nextDouble() and nextLine() for the appropriate data.

Java

import java.util.Scanner;

public class ScannerDemo {

nextLine() reads the rest of a line, including spaces. The extra call after nextInt() consumes the pending newline so it does not become an empty name.

Method overriding occurs when a subclass provides a new implementation of an inherited instance method with the same signature (and a compatible return type). At run time, the implementation is selected using the actual object type, enabling dynamic dispatch. Use @Override so the compiler checks the declaration. class Dog extends Animal {

    }

public class OverrideDemo {
    public static void main(String[] args) {

    }
}

Q.4 (b) Explain throw keyword with example.4 marks

Question as printed: Q.4 (b) Explain throw keyword with example.

The throw statement explicitly throws one exception object at a particular point in a method. Control transfers to the nearest matching catch handler; if none exists, the exception propagates to the caller. A checked exception must be caught or declared with throws; unchecked exceptions need not be declared.

Java

public class ThrowDemo {
    static void validateAge(int age) {
        if (age < 18) {
            throw new IllegalArgumentException(
                "Age must be at least 18");
        }
        System.out.println("Eligible");
    }

    public static void main(String[] args) {
        try {
            validateAge(16);
        } catch (IllegalArgumentException e) {
            System.out.println("Rejected: " + e.getMessage());
        }
    }
}

The program creates and throws an IllegalArgumentException; the catch block handles it and prints a clear message.

Q.4 (c) Create a Java program to demonstrate exception handling using built-in exceptions (divide by zero).7 marks

Question as printed: Q.4 (c) Create a Java program to demonstrate exception handling using built-in exceptions (divide by zero).

Integer division by zero raises the built-in unchecked ArithmeticException. The divisor below is a variable so the failure occurs when the program runs and can be caught.

Java

public class DivideByZeroDemo {
    public static void main(String[] args) {
        int numerator = 20;
        int denominator = 0;

        try {
            int result = numerator / denominator;
            System.out.println("Result = " + result);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide an integer by zero.");
        } finally {
            System.out.println("Division attempt finished.");
        }
    }
}

The catch block handles the exception, and the finally block runs during normal completion or after the handled exception. The program does not terminate with an uncaught divide-by-zero error.

final restricts further modification according to the kind of declaration:

Reassigning maxAttempts, overriding showId(), or creating a subclass of Constants would be a compile-time error.

Q.4 (b) Explain throws keyword with example.4 marks

Question as printed: Q.4 (b) Explain throws keyword with example.

The throws clause appears in a method or constructor declaration to state that the method may pass one or more exceptions to its caller. The caller must catch a checked exception or declare it in turn. throws declares possible propagation; it does not itself throw an exception (that is done by throw).

Java

import java.io.BufferedReader;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;

public class ThrowsDemo {
    static String firstLine(Path file) throws IOException {
        try (BufferedReader reader = Files.newBufferedReader(file)) {
            return reader.readLine();
        }
    }

    public static void main(String[] args) {
        try {
            System.out.println(firstLine(Paths.get("input.txt")));
        } catch (IOException e) {
            System.out.println("Could not read file: " + e.getMessage());
        }
    }
}

IOException is checked, so firstLine declares it and main handles it. Try-with-resources closes the reader automatically.

Q5 · Lambdas, streams and Java AI libraries

Q.5 (a) Explain Lambda Expression in java with example.3 marks

Question as printed: Q.5 (a) Explain Lambda Expression in java with example.

A lambda expression is a concise implementation of the single abstract method of a functional interface. Its general form is (parameters) -> expression or (parameters) -> { statements; }. Lambdas were added in Java 8 and are commonly used with callbacks, collections and streams.

Java

@FunctionalInterface
interface Greeting {
    String sayHello(String name);
}

public class LambdaDemo {
    public static void main(String[] args) {
        Greeting g = name -> "Hello, " + name;
        System.out.println(g.sayHello("Asha"));

        java.util.List<Integer> values =
                java.util.Arrays.asList(2, 4, 6);

The compiler infers the parameter type from the target interface. The lambda supplies behaviour; Greeting supplies the method contract.

Question as printed: Q.5 (c) Write a Java program to create a new HashSet and add 5 students name in that HashSet.

A HashSet stores unique elements. It does not guarantee iteration order, so the printed order may differ from insertion order.

Java

import java.util.HashSet;
import java.util.Set;

public class StudentSetDemo {
    public static void main(String[] args) {
        Set<String> students = new HashSet<>();
        students.add("Asha");
        students.add("Bharat");
        students.add("Charu");
        students.add("Dev");
        students.add("Esha");

        for (String name : students) {
            System.out.println(name);
        }
        System.out.println("Unique names = " + students.size());
    }
}

Adding a duplicate name would not create a second set element; size() therefore counts unique names.

Q.5 (a) OR Explain Stream API in java with example.3 marks

Question as printed: Q.5 (a) OR Explain Stream API in java with example.

The Stream API (Java 8+) processes a sequence of elements through a pipeline. A source supplies elements; intermediate operations such as filter and map are lazy and return another stream; a terminal operation such as forEach, count or collect triggers processing. A stream does not store data or normally mutate its source.

Java

import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class StreamDemo {
    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5, 6);

        List<Integer> evenSquares = numbers.stream()
                .filter(n -> n % 2 == 0)
                .map(n -> n * n)
                .collect(Collectors.toList());

        System.out.println(evenSquares); // [4, 16, 36]
    }
}

The pipeline selects even numbers, maps each to its square, and collects the result in a new list. A stream is single-use; call stream() again for another pipeline.

Q.5 (c) OR How to Implement Multiple Inheritance using Interface in java? Explain with example.7 marks

Question as printed: Q.5 (c) OR How to Implement Multiple Inheritance using Interface in java? Explain with example.

Java classes cannot extend more than one class because multiple implementation inheritance can create ambiguity. A class can, however, implement multiple interfaces, inheriting several type contracts and providing the required method implementations.

Java

interface Printable {
    void print();
}

interface Savable {
    void save();
}

class Report implements Printable, Savable {
    @Override
    public void print() {
        System.out.println("Printing report");
    }

    @Override
    public void save() {
        System.out.println("Saving report");
    }
}

public class InterfaceDemo {
    public static void main(String[] args) {
        Report report = new Report();
        report.print();
        report.save();
    }
}

Report is a subtype of both Printable and Savable. The class supplies both methods. Interfaces can also contain default methods; conflicting defaults must be resolved explicitly.

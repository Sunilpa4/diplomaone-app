Q1 · Algorithms and C program basics

Q1(a) Define Algorithm? Give advantages and disadvantages of Algorithm.3 marks

Question: Q1(a) Define Algorithm? Give advantages and disadvantages of Algorithm.

Algorithm: a finite, ordered set of clear and unambiguous steps that solves a specified problem and produces a result. It is a language-independent plan; a C program is one implementation of that plan.

A good algorithm has zero or more inputs, at least one output, definite steps, a finite stopping point and effective steps that can be carried out.

Advantages: easy to understand and communicate; independent of programming language; helps plan a program before coding; supports checking and debugging logic; relatively easy to modify.

Disadvantages: lengthy to write for a large problem; text is less visual than a flowchart; branches and loops can be harder to follow; there is no single compulsory notation for pseudocode.

Q1(b) Explain the General Structure of C Program.4 marks

Question: Q1(b) Explain the General Structure of C Program.

A C source file is commonly arranged in these sections:

  1. Documentation/comments: program purpose, author or date.
  2. Preprocessor/link section: header files such as #include <stdio.h> and symbolic constants with #define.
  3. Global declarations: global variables and function prototypes, if required.
  4. main function: local declarations, executable statements and a return status.
  5. User-defined function definitions: supporting functions, if the program uses them.

A minimal, well-formed example is:

C code

/* Documentation: demonstrate a C program */
#include <stdio.h>            /* Link/header section */
#define LIMIT 10              /* Definition section */
int main(void)                /* Main function */
{
    int value = LIMIT;        /* Local declaration */
    printf("%d\n", value);   /* Executable statement */
    return 0;
}

Question: Q1(c) Write a C program to find the area of a circle.

For radius r, area = πr². Read the radius, calculate using a floating-point type and print the result. This program rejects a negative radius.

#include <stdio.h>

int main(void)
{

        printf("Invalid radius.\n");
        return 1;
    }
    area = PI * radius * radius;

    return 0;
}

Question: Q1(c) OR · Write a C program to find the maximum number out of given three numbers.

Read three integers and compare them. The >= comparisons also handle equal maximum values.

}

Q2 · Decisions and loops

Q2(a) Define Nested If-else statement with their syntax and flowchart.3 marks

Question: Q2(a) Define Nested If-else statement with their syntax and flowchart.

A nested if-else places one if or if-else inside another branch. The inner condition is tested only when execution enters its containing branch. Braces make the association clear.

General syntax

if (condition1) {
    if (condition2) {
        statement1;
    } else {
        statement2;
    }
} else {
    statement3;
}

Flow: test the outer condition; follow its true or false branch; where an inner decision appears, test it and follow one of its two outcomes; then continue after the branches rejoin.

Q2(b) Explain while loop and do-while loop with example.4 marks

Question: Q2(b) Explain while loop and do-while loop with example.

while: an entry-controlled loop. It tests the condition before the body, so the body may execute zero times.

while example

int i = 1;
while (i <= 3) {
    printf("%d ", i);
    i++;
}

do-while: an exit-controlled loop. It executes the body first and tests afterwards, so the body executes at least once. A semicolon follows the condition.

do-while example

int j = 1;
do {
    printf("%d ", j);
    j++;
} while (j <= 3);

Both repeat while their condition remains true; initialise and update the controlling variable to avoid an unintended infinite loop.

Question: Q2(c) Write a C program to print 10 to 1 number using do while loop.

Start at 10, print the current value, decrement it, and repeat while it is at least 1.

Q2(a) OR · Define If-else statement with their syntax and flowchart.3 marks

Question: Q2(a) OR · Define If-else statement with their syntax and flowchart.

An if-else statement is a two-way selection statement. If the condition is non-zero (true), the if block executes; otherwise, the else block executes. Only one branch is selected.

Syntax

if (condition) {
    statement1;   /* true branch */
} else {
    statement2;   /* false branch */
}

The flowchart tests one condition, labels its two outgoing paths Yes/True and No/False, performs the corresponding action, then rejoins.

Q2(b) OR · Explain Break and continue statements with example.4 marks

Question: Q2(b) OR · Explain Break and continue statements with example.

break immediately terminates the nearest enclosing loop or switch; control continues after it. continue skips the remaining statements in the current loop iteration and proceeds to the next iteration (the condition/update still follows the rules of that loop).

C code

#include <stdio.h>
int main(void)
{
    int i;
    for (i = 1; i <= 10; i++) {
        if (i == 5)
            continue;   /* skip 5 */
        if (i == 8)
            break;      /* stop before 8 */
        printf("%d ", i);
    }
    return 0;
}

Output: 1 2 3 4 6 7.

Q2(c) OR · Write a Program to display Sum of digits using While loop.7 marks

Question: Q2(c) OR · Write a Program to display Sum of digits using While loop.

Repeatedly take the last digit with remainder by 10, add it, and remove that digit by integer division by 10. The program accepts a non-negative integer; for input 0 the sum is 0.

C code

#include <stdio.h>
int main(void)
{
    int number, original, sum = 0;
    printf("Enter a non-negative integer: ");
    if (scanf("%d", &number) != 1 || number < 0) {
        printf("Invalid input.\n");
        return 1;
    }
    original = number;
    while (number > 0) {
        sum += number % 10;
        number /= 10;

    printf("Sum of digits of %d = %d\n", original, sum);
    return 0;
}

Q3 · Arrays and pointers

Q3(a) List and Define Array. How to declare and initialize 1-D array.3 marks

Question: Q3(a) List and Define Array. How to declare and initialize 1-D array.

An array is a fixed-size collection of elements of the same data type stored in consecutive memory locations and referred to by one name. A one-dimensional array uses one index; in C indexing starts at 0.

C code

int marks[5];                 /* declaration: indexes 0 to 4 */
int values[5] = {10, 20, 30, 40, 50};
int first_three[5] = {1, 2, 3}; /* remaining elements become 0 */
int all_zero[5] = {0};
/* access an element: values[0] */

The declared size determines the valid index range. Accessing outside it is undefined behaviour.

Q3(b) Explain Pointer with their Declaration, Initialization and Example.4 marks

Question: Q3(b) Explain Pointer with their Declaration, Initialization and Example.

A pointer is an object whose value is an address. A pointer type identifies the type of object it can point to. The address-of operator & obtains an object's address; unary * dereferences a valid pointer to access that object.

C code

int number = 25;
int *ptr;                 /* declaration: pointer to int */
ptr = &number;            /* initialization with address */
printf("%d\n", *ptr);     /* reads 25 through the pointer */
*ptr = 40;                /* changes number to 40 */
printf("%d\n", number);

Initialise a pointer before dereferencing it. Use a matching pointer type, and print an address with %p after converting it to (void *).

Question: Q3(a) OR · List and Define Array. How to declare and initialize 2-D array.

An array stores a fixed number of same-type elements under one name. A two-dimensional array is an array of one-dimensional rows, accessed with a row index and a column index. C stores its elements in row-major order.

Q3(b) OR · Explain Types of Pointer : Void and Null.4 marks

Question: Q3(b) OR · Explain Types of Pointer : Void and Null.

Void pointer: void * is a generic pointer type that can hold the address of an object of any object type. It must be converted to a suitable object-pointer type before dereferencing; standard C does not permit arithmetic directly on void *.

void pointer example

int value = 25;
void *vp = &value;
printf("%d\n", *(int *)vp);

Null pointer: a pointer value that is guaranteed not to point to an object or function. Use the NULL macro (from <stddef.h> or a standard library header) to initialise or test a pointer. Never dereference a null pointer.

null pointer example

int *p = NULL;
if (p == NULL) {
    printf("Pointer is not assigned.\n");
}

A void * describes a generic pointer type; a null pointer describes a pointer value/state. They are different concepts.

Q3(c) OR · Write a program to add two matrix of size 3X3 2-D array.7 marks

Question: Q3(c) OR · Write a program to add two matrix of size 3X3 2-D array.

Read corresponding elements of two 3 × 3 matrices and add them element by element: C[i][j] = A[i][j] + B[i][j].

C code

#include <stdio.h>
int main(void)
{
    int a[3][3], b[3][3], c[3][3];
    int i, j;
    printf("Enter 9 elements of matrix A: ");
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            if (scanf("%d", &a[i][j]) != 1) return 1;
    printf("Enter 9 elements of matrix B: ");
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            if (scanf("%d", &b[i][j]) != 1) return 1;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            c[i][j] = a[i][j] + b[i][j];
    printf("Sum matrix:\n");
    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3; j++)
            printf("%d\t", c[i][j]);
        printf("\n");
    }
    return 0;
}

Q4 · Functions and strings

Q4(a) Define is user defined function (UDF) and library function? Explain with two example of each.3 marks

Question: Q4(a) Define is user defined function (UDF) and library function? Explain with two example of each.

A user-defined function (UDF) is a function written by the programmer to perform a named task; it is declared/prototyped, defined and called by the program.

A library function is supplied by the C standard library or another library and is declared through its header. Examples:

  • UDF: int add(int a, int b) written by the programmer; void display(void) written by the programmer.
  • Library: printf() and scanf() from <stdio.h>; strlen() from <string.h> is another example.

Library examples are ready-made; a UDF can organise a problem into reusable modules.

Q4(b) Explain strlen( ) and strcpy( ) function with Example.4 marks

Question: Q4(b) Explain strlen( ) and strcpy( ) function with Example.

Both functions are declared in <string.h> and work with null-terminated character strings.

  • strlen(s): returns the number of characters before the terminating '\0'; the terminator is not counted. Its return type is size_t.
  • strcpy(destination, source): copies the source string, including its null terminator, into destination and returns destination. The destination must have enough space and must not overlap the source.
C code

#include <stdio.h>
#include <string.h>
int main(void)
{
    char source[] = "GTU";
    char destination[10];
    size_t length = strlen(source);
    strcpy(destination, source);
    printf("Length = %zu\n", length);
    printf("Copy = %s\n", destination);
    return 0;
}

Here length is 3; the copied array contains four bytes including '\0'.

Q4(c) Write a program to find factorial of a given number using recursion.7 marks

Question: Q4(c) Write a program to find factorial of a given number using recursion.

Recursion occurs when a function calls itself. Factorial uses the base case 0! = 1 and recurrence n! = n × (n−1)!. This example accepts 0 through 20 so the result fits the common 64-bit unsigned long long range.

C code

#include <stdio.h>
unsigned long long factorial(unsigned int n)
{
    if (n <= 1)
        return 1;                 /* base case */
    return n * factorial(n - 1);  /* recursive case */
}
int main(void)
{
    int n;
    printf("Enter an integer from 0 to 20: ");
    if (scanf("%d", &n) != 1 || n < 0 || n > 20) {
        printf("Input out of range.\n");
        return 1;
    }
    printf("Factorial = %llu\n", factorial((unsigned int)n));
    return 0;
}

Q4(a) OR · Define recursion with example.3 marks

Question: Q4(a) OR · Define recursion with example.

Recursion is a method in which a function solves a problem by calling itself on a smaller instance of the same problem. A recursive solution needs:

  • Base case: stops recursion.
  • Recursive case: reduces the problem and calls the function again.

Example: factorial is defined by factorial(0) = 1 and factorial(n) = n × factorial(n−1) for positive n. Without a reachable base case, calls do not terminate normally and may exhaust the call stack.

Q4(b) OR · Explain Any Three String Handling Function with Example.4 marks

Question: Q4(b) OR · Explain Any Three String Handling Function with Example.

String functions in <string.h> process null-terminated character arrays. Three examples:

  1. strlen(s): returns the character count excluding '\0'.
  2. strcpy(dst, src): copies src, including its terminator; ensure dst has enough capacity.
  3. strcmp(a, b): compares strings lexicographically; returns 0 if equal, a negative value if the first differing character in a is smaller, and a positive value if it is greater.
C code

#include <stdio.h>
#include <string.h>
int main(void)
{
    char first[] = "CAT";
    char copy[10];
    printf("Length = %zu\n", strlen(first));
    strcpy(copy, first);
    printf("Copy = %s\n", copy);
    printf("Compare = %d\n", strcmp(first, "DOG"));
    return 0;
}

Do not compare strings with ==; use strcmp(). Do not copy into a destination that is too small.

Q5 · Text files and function categories

Q5(a) Define fopen() & fclose() functions with examples.3 marks

Question: Q5(a) Define fopen() & fclose() functions with examples.

fopen(), declared in <stdio.h>, opens a named file in a specified mode and returns a FILE * stream pointer. It returns NULL if the file cannot be opened. Always check the result.

fclose(fp) closes an open stream, flushes buffered output and releases the stream; it returns 0 on success and EOF on failure.

C code

#include <stdio.h>
int main(void)
{
    FILE *fp = fopen("notes.txt", "w");
    if (fp == NULL) {
        perror("notes.txt");
        return 1;
    }
    fputs("C file example\n", fp);
    if (fclose(fp) == EOF) {
        perror("fclose");
        return 1;
    }
    return 0;
}

Q5(b) Explain All Text modes in files.4 marks

Question: Q5(b) Explain All Text modes in files.

Pass the mode string as the second argument to fopen(filename, mode). In standard C, text mode is the default when b is absent.

ModePurpose and file effect
rRead only; file must exist; starts at beginning.
wWrite only; creates a file or truncates an existing file to empty.
aAppend only; creates if absent; every write goes to end of file.
r+Read and write/update; file must exist; does not truncate.
w+Read and write/update; creates or truncates the file.
a+Read and append/update; creates if absent; writes are forced to the end.

Close and reopen when changing modes unless using an update mode correctly. When switching between input and output on an update stream, follow C's positioning/flush requirements. Use rb, wb etc. for binary files, not text mode.

Q5(a) OR · Define File. List files operations and explain any one.3 marks

Question: Q5(a) OR · Define File. List files operations and explain any one.

A file is a named collection of related data stored on secondary storage so that it can be retained and used after a program ends.

Common file operations: create/name, open, read, write, append/update, reposition, close, rename and delete.

Q5(b) OR · Explain fprintf() and fscanf() function in Text modes reading and writing files.4 marks

Question: Q5(b) OR · Explain fprintf() and fscanf() function in Text modes reading and writing files.

fprintf() and fscanf() are formatted text-file functions from <stdio.h>. fprintf(fp, format, ...) writes formatted characters to a file stream. fscanf(fp, format, ...) reads formatted fields from a stream and stores values through the supplied addresses; it returns the number of successful assignments (or EOF when input fails before the first assignment).

C code

#include <stdio.h>
int main(void)
{
    FILE *fp;
    int roll;
    char name[20];
    float marks;

    fp = fopen("marks.txt", "w");
    if (fp == NULL) return 1;
    fprintf(fp, "%d %s %.2f\n", 101, "Ravi", 85.5f);
    fclose(fp);

    fp = fopen("marks.txt", "r");
    if (fp == NULL) return 1;
    while (fscanf(fp, "%d %19s %f", &roll, name, &marks) == 3)
        printf("%d %s %.2f\n", roll, name, marks);
    fclose(fp);
    return 0;
}

The width %19s protects the 20-byte name array, including its terminating null character. Test the assignment count instead of assuming that each read succeeded.

Q5(c) OR · Explain Call by Value and Call by Reference with Example.7 marks

Question: Q5(c) OR · Explain Call by Value and Call by Reference with Example.

Call by value: the function receives a copy of the argument value. Changing its parameter does not change the caller's variable.

Reference-style modification in C: C still passes every argument by value, but a pointer argument carries a copied address. Dereferencing it lets the function modify the caller's object. Textbooks often call this “call by reference”; technically, C has no true reference parameter type.

C code

#include <stdio.h>
void addTenValue(int n)
{
    n += 10;              /* changes only the copy */
}
void addTenByPointer(int *n)
{
    *n += 10;             /* changes the caller's object */
}
int main(void)
{
    int value = 5;
    addTenValue(value);
    printf("After value call: %d\n", value); /* 5 */
    addTenByPointer(&value);
    printf("After pointer call: %d\n", value); /* 15 */
    return 0;
}

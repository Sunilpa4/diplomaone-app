# DiplomaOne – GTU Diploma app (Flutter: Android + Web)

Notes · Programs · Flowcharts/Diagrams · Equations · Numericals · Syntax · Viva · Exam Qs
for GTU Diploma students, in the purple card design from the reference screenshot.

## Screens
Home → All Branches (27) → Semesters (1–6) → Subjects → Subject (units, exam scheme,
paper solutions) → Unit (tabs with tap-to-open cards, inline diagrams, zoom viewer).
Search (name / old code / new "C" code), Continue reading, EN ⇄ ગુ toggle (saved on the device).

## Code structure
| Path | What |
|---|---|
| `lib/main.dart` | App start, theme, phone-width layout on desktop web |
| `lib/theme.dart` | App name + colours (`AppInfo`, `C`) |
| `lib/l10n.dart` | UI strings EN/GU (`L()`), content language picker (`tr()`) |
| `lib/state.dart` | Language + recently opened units (shared_preferences) |
| `lib/data/repository.dart` | `ContentSource` (now: bundled assets; next: Firestore) + cache |
| `lib/screens/home_screen.dart` | Home |
| `lib/screens/browse.dart` | Branches, Semesters, Subjects, Search |
| `lib/screens/subject_screen.dart` | Subject page |
| `lib/screens/unit_screen.dart` | Unit page with all tabs |
| `lib/widgets/` | Cards/headers, HTML renderer, code highlighter (C/Python), SVG + zoom |
| `lib/ads/` | AdMob banner on Android, placeholder on web (`ad_config.dart` = ad ids) |
| `assets/content/` | Generated by `tools/export_app_content.py` (do not edit by hand) |
| `assets/fonts/` | DejaVu Sans / Mono (diagrams were checked with these) |
| `test/all_content_test.dart` | Renders every card of every unit and reports layout errors |

## Adding content
1. Write/build the unit as usual (`tools/build_<CODE>_u<N>.py` → `content/...`).
2. Add the subject to `SUBJECTS` / `BRANCH_SEMS` in `tools/export_app_content.py` if new.
3. `python3 tools/export_app_content.py` → refreshes `assets/content/`.
4. `flutter test test/all_content_test.dart` → must print `0 bad` for every unit.
(After Firebase is connected, step 3 output is uploaded through the admin panel instead –
no app update needed.)

## Build (in a fresh sandbox)
```bash
bash tools/setup_build_env.sh android   # swap + Flutter 3.47.8 + Java 17 + Android SDK (all in /opt)
source tools/build_env.sh
cd app && flutter pub get
flutter build web --release --no-wasm-dry-run --no-web-resources-cdn   # → build/web  (~1 min)
flutter build apk --release --split-per-abi   # → arm64 / armv7 / x86_64 APKs (first build ~18 min, then ~4 min)
flutter build appbundle --release             # → .aab for the Play Store
```
Afterwards delete `~/.android`, `app/.dart_tool`, `app/android/.gradle` (big, auto-recreated).

## Signing key (VERY IMPORTANT)
`android/app/upload-keystore.jks` + `android/key.properties` (password inside) sign every release.
Download both and keep them safe (Google Drive + pen drive). The Play Store only accepts updates
signed with the same key (with Play App Signing a lost upload key can be reset, but it takes days).

## Before publishing
- Replace the AdMob TEST ids: `lib/ads/ad_config.dart` and `android/app/src/main/AndroidManifest.xml`.
- Package id: `com.diplomaone.app` (cannot be changed after the first Play Store upload).
- App icon, signing key, privacy policy (required for AdMob / Play Store).

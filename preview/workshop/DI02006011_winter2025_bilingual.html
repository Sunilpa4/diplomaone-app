Q1 · RF, offsets and principles

Q.1 (a) Define: (1) Representative fraction (2) Plan (3) Map (03 marks)Q.1 (a) Define: (1) Representative fraction (2) Plan (3) Map (03 marks)03 marks૦૩ ગુણ

RF: Ratio map distance to ground distance same unit — e.g. 1:50000 means 1cm =500m.

Plan: Large scale 1:500-5000, small area, curvature ignored, engineering detail.

Map: Small scale 1:50000+, large area, curvature considered, topography.

RF: નકશા અને જમીન અંતર નો ગુણોત્તર — 1:50000 એટલે 1cm =500m.

Plan: મોટો scale નાનો વિસ્તાર, Map: નાનો scale મોટો વિસ્તાર.

Q.1 (b) Define: (1) Offset (2) Tie line (3) Base line (4) Check line (04 marks)Q.1 (b) Define: (1) Offset (2) Tie line (3) Base line (4) Check line (04 marks)04 marks૦૪ ગુણ

Offset: Perpendicular distance from chain line to detail. Tie line: Joins two tie stations to locate interior detail. Base line: Longest main line on which framework rests. Check line: Joins apex to side to verify accuracy.

Offset લંબ અંતર, Tie line interior બિંદુ જોડે, Base line સૌથી લાંબી, Check line ચકાસણી.
